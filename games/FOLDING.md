# 折叠与分组的修订：开发文档

给接手实现的会话。先读 `games/DESIGN.md` 第 6.10 节的 **Pipeline sections** 和 **Player settings** 两段（分段、分割线、设置已经做完，见提交 `ec325f1` … `bf79ed8`），再读本文。本文只改**折叠后的样子和分组的样子**，分段的来历、分割线的数据（`board.sections`）、设置面板都不变。

## 1. 问题

用户看了做出来的效果，两处要改：

- **桌面折叠示意图很怪。** 折叠的段画成了另一张图（`circuit/StageDiagram.jsx`：小方框、口名小标签、线在框间穿），和板上元件的样子对不上；手机紧凑格位用元件的 `mini` 面，也是另一种样子。
- **分组做成了卡片。** 组有自己的边框和标题栏，像又一层卡片，板上一层套一层。

## 2. 新的设计（桌面和手机一致）

1. **折叠的元件 = 原来的元件卡，只是不显示配置和结果。** 卡片头（图标、名字、ⓘ、删除）和口（左侧输入口带口名、右侧输出口）照旧，位置照旧；卡片主体里的设置控件、读数、值的预览、摘要都不画，卡片只剩「头 + 口那几行」的高度。线照常接在这些口上。参照：一张「逐行汇总」卡去掉中间的读数矩阵，就是它折叠后的样子。
2. **分组只是一块淡底。** 像 Figma 的 section：组内元件所占区域外扩一圈内边距，铺一层很淡的底色（比画布底色深或浅一档，不画边框，或者极淡的边），组名（批注）写在淡底左上角，旁边一个折叠钮。不画卡片头、不画卡片边框、不另起一套卡片样式。淡底由组内元件的位置和大小自动算出，不能单独拖动；它画在线和元件下面。
3. **折叠一组 = 组内每个元件都变成第 1 条的样子；展开 = 恢复完整。** 元件不搬家、不藏起来、不换成别的图。
4. **手机一样。** 一节（两条分割线之间）也是一块淡底，分割线和批注在淡底顶上；折叠一节 = 节内格子都变成第 1 条的样子（格位里的头 + 口）。工具行的「全部折叠」就是所有元件都变成第 1 条的样子，格子照旧变窄、左侧窄边照旧留给分割线。DESIGN 里「a fold toggle reduces the rows to the divider, its note and a part count」改掉：折叠不再把行收成一条线。
5. **元件的第四面 `mini` 不要了。** 折叠的样子由 kit 统一画（元件卡去掉主体），开发者不必另配一面。删掉 parts.json 的 `views.mini`、它的 schema、默认规则、渲染（`shell/parts/MiniFace.jsx`）、studio 的第四栏，DESIGN 第 6.9 节改回三面视图。已经写了 `mini` 的内容（《视觉实验室》的「四则运算」）一并删掉，`npm run op -- vision-lab adopt --why "…"`。
6. **删掉折叠示意图**：`circuit/StageDiagram.jsx`，以及「缩到 9px 以下换成名字链」那套。`circuit/layout.js` 的分列排版保留（`svg.js`、「整理」、初次落位还在用）。
7. **线。** 元件都在原位，线照常画。`circuit/connections.js` 的标签规则保留；由于不再有示意图，「跨过折叠段」这一类不再存在，只剩跨组、扇出到两组以上、很长的线。桌面上看效果定默认：若桌面照常画线已经清楚，设置项「跨段连线画成标签」桌面默认关、手机默认开，在报告里说明理由。

## 3. 步骤

每步一次提交，直接推到 main（先 `git pull --rebase`）。

- **3a 折叠的元件卡。** `CanvasEditor.jsx`、`SlotBoard.jsx` 的卡片各有一个折叠状态，只画头和口；`CircuitLevel.jsx` 按组（节）的 `folded` 和「全部折叠」把它传下去。删掉 `StageDiagram.jsx` 和第 2 节第 5 条的 `mini` 面全套。词汇表变了的领域照例删 `versions/1.json` 后 `npm run versions` 重印。
- **3b 淡底。** 桌面画布上每组一块淡底（在线和卡片之下），组名和折叠钮在左上；手机每节一块淡底，分割线和批注在顶上。颜色、圆角、内边距取 tokens；需要新变量就在 `kit/tokens.css` 游戏层加（例如 `--group`），几套主题都调到合适。删掉现在组和节的卡片边框、标题栏样式。
- **3c 线的默认。** 按第 2 节第 7 条定设置项「跨段连线画成标签」的默认值（可按桌面、手机分别给默认），写进 DESIGN。
- **3d 文档。** DESIGN 第 6.9 节回到三面视图；第 6.10 节 **Pipeline sections** 改写折叠和分组的样子，删掉示意图、`mini`、名字链的描述。本文件做完后删掉，`games/PLAN.md` 进度里记一行。

## 4. 验收

- 同一块扫描仪板（《视觉实验室》第 1 章最后一关）：桌面折叠前后是同一批元件、同样的位置、同样的连线，折叠后只是变矮；分组只有淡底和组名，没有卡片边框和标题栏。
- 手机：「全部折叠」和单节折叠各一张；折叠后格子是「头 + 口」，不是另一种卡片。
- 浅色、深色主题各看一遍；studio 的元件编辑器只有三栏。
- 折叠、展开、改批注都不改变运行和判定：跑通一关。
