# 《状态之图》新关卡树

按 [`games/DESIGN.md`](../DESIGN.md) 从头设计的一套关卡树。它不是对现有关卡的重排：先定每台机器人能做什么，再定它开启的问题、它最重要的专题、它的挑战，最后才看现有关卡里有哪些素材可以直接改写。

**终点：** 学完以后，学习者看到一个新问题，能自己定出"表的形状 + 状态 + 规则 + 顺序"，挑一台合适的机器人，把电路板拼出来。

**每台机器人的结构**（第 0 代"纸笔"除外）：

```
地基（按顺序）→ 练习（按难度曲线）→ 专题系列（引入 → 递进 → 终极谜题）
                     └── 挑战（可跳过，挂在某一关之后）
```

**关卡树（`levels/eras.js`）：** 主线上互不依赖的几串关，排成必修的并行组：先后随意，全部通过才继续。专题和挑战是可选支线，挂在它们需要的那一关之后。

| 代 | 主线 |
|---|---|
| 1 | 传话 → 两路汇合 → 认出起点 → 拼一台机器 → [石头：落石、能不能到 ∥ 花费：最省力] → [换形状：斜街、杨辉三角 ∥ 金币：最值钱的路] → 有坑也有价 |
| 2 | 爬楼梯 → [倒着扫：倒着算 ∥ 输赢：拿石子] → 连线不交叉 → 对齐表 → 回文 → [有坏台阶的楼梯 ∥ 最长回文子序列] |
| 3 | 青蛙过河 → [跳法：跳得更远、安全过河 ∥ 句子：猜词性、这句话有多可能] |
| 4 | 前面所有的 → 越来越高 → [区间：合并石子、顺序不止一种、句子的骨架 ∥ 零钱：凑零钱] |

第 0、5、6 代仍是一条线（第 5 代的「找出破绽」接着「不能连着偷」失败时找到的反例）。专题挂在：图里的缝 → 最省力之后，拼写纠错 → 对齐表之后，背包 → 跳得更远之后，切单词 → 越来越高之后，设计状态 → 钥匙与门之后，格子世界 → 格子世界（练习）之后；最大的正方形挂在杨辉三角之后，最大的一段挂在前面所有的之后。下面各代的表仍按设计时的编号写。

## 1. 元件从哪里来

### 1.1 原始元件：动态规划之外的算术和逻辑

每个原始元件在一关里第一次出现，一关只出现一个。汇合器的几种型号是同一个元件，换型号不算新东西。

| 元件 | 第一次出现 | 为什么在这里 |
|---|---|---|
| 汇合器（加起来） | 1-2 两路汇合 | 第一次需要把两个来路合起来 |
| 常数 + 放行闸 | 1-3 认出起点 | 起点要"凭空"放进一个 1 |
| 拦截闸 | 1-5 落石 | 第一次需要把一格掐断 |
| 加法器 | 1-6 最省力 | 第一次要在来路上加一个数 |
| 汇合器换型号（取较小 / 取较大 / 任一是） | 1-6 / 1-9 / 1-7 | 同一张表回答别的问题 |
| 取反 | 2-3 拿石子 | 第一次需要"对手输 = 我赢" |
| 乘法器 | 3-3 安全过河 | 第一次要把可能性连乘 |

### 1.2 机器人的能力：每一代地基里教

每个机器人在 `kit/domains/table/circuit/robots.js` 里写明自己会什么（`can`）。从远望起，后来的机器人保留前面的能力；只有更大的视野、不同的手臂是某个机器人自己的身体。

| 能力 | 谁会 | 在哪一关教 |
|---|---|---|
| 3×3 视野（点格子加输出口） | 所有机器人 | 1-1 传话 |
| 本格信息（点一条信息加输出口） | 所有机器人 | 1-3 认出起点 |
| 5×5 视野 | 远望、长臂 | 2-1 爬楼梯 |
| 换扫描顺序：倒着扫 | 远望起 | 2-2 倒着算 |
| 读表头：上面一个词、左边一个词（两字相同） | 远望起 | 2-5 对齐表 |
| 换扫描顺序：按长度扫 | 远望起 | 2-6 回文 |
| 伸缩臂（视野卡片上的臂格） | 长臂 | 3-1 青蛙过河 |
| 扫描臂、筛选 | 扫帚 | 4-1 前面所有的、4-2 越来越高 |
| 一步写好几格（一格存好几个数） | 千层起 | 5-1 不能连着偷 |
| 多层表、探针 | 千层起 | 5-3 钥匙与门 |
| 反复扫 | 回环 | 6-1 绕一圈 |

小方只会 3×3 视野和本格信息，只按"逐行，从左上开始"扫，一步只写一格。

**两条规则（课程审计检查）：**
- 地基、练习、专题的终极谜题和挑战，都由这一代的机器人来做；只有专题的引入和过渡关可以借用更早的机器人。
- 机器人得会做一关的参考解用到的一切：审计从参考解读出用到的机制（`kit/domains/table/course.js` 的 `usesOf`），和机器人的能力对照。

### 1.3 学习者造的封装件：常用的元件组合

封装的是在许多关里反复出现的元件组合，和机器人无关。每个都在它第一次自然出现的那一关造出来；之后凡是用数字的关（托盘里有汇合器），都会自动出现在托盘里。

| 封装件 | 做什么 | 在哪一关造 | 后面用在哪里（参考解） |
|---|---|---|---|
| 起点值 | 条件是「是」时给出卡片上的数，否则「—」 | 1-3 认出起点 | 1-4 拼一台机器、1-6 最省力；之后几乎每张表的起点 |
| 路线计数器 | 两条来路加起来，起点放 1 | 1-4 拼一台机器 | 1-5 落石、1-8 斜街、1-10 杨辉三角、2-2 倒着算、2-5 有坏台阶的楼梯、3-2 跳得更远、钥匙那几关 |
| 最省格 | 最多三条来路取较小，起点放 0，加本格代价 | 1-6 最省力 | 1-11 有坑也有价、S2 可以斜着走、S3 最不起眼的缝 |
| 择优器 | 取较大（不换，换来 + 加上） | K2 背包表 | K3、K4、挑战「最大的一段」、5-4 买卖一次股票、5-5 冷冻期 |
| 打折器 | 最多四条来路取最大，乘卡片上的折扣 | 6-2 格子世界 | V1 往右往下找宝藏、V3 有冰有地 |

只在一处用到的电路板（编辑距离计、区间合并器）仍然只在用到它的那几关出现。「台阶计数器」已经去掉：它和路线计数器是同一个组合。

---|---|---|
| 路线计数器（上 + 左，起点放 1） | 1-4 拼一台机器 | 1-5 落石、1-8 斜街 |
| 最省力格（取较小（上，左）+ 本格花费） | 1-6 最省力 | 1-11 有坑也有价 |
| 台阶计数器（前 1 级 + 前 2 级） | 2-1 爬楼梯 | 2-5 有坏台阶的楼梯 |
| 编辑距离计 | 专题 E2 改错字 | 专题 E3 你是想打这个词吗 |

不在后面复用的电路板，就不打包成封装件。

## 2. 第 0 代 · 纸笔

还没有机器人。用手和箭头弄明白：一格的答案由它的来路拼出来。

**地基**

| 关 | 名称 | 新东西 | 规格要点 | 素材 |
|---|---|---|---|---|
| 0-1 | 找路线 | 路线可以一条条数 | 在 2×3 地图上画出所有路线 | trace |
| 0-2 | 只看最后一步 | 到一格的路线数 = 所有上一站之和；起点算 1 | 手填一张小镇地图 | lastStep |
| 0-3 | 棋盘城市 | 每个路口重复同一件事；先填上面和左边 | 手填 4×5 | city |

0-3 的结尾点明填的顺序：一个路口要等上面和左边都填好，机器人也按这个顺序（逐行，从左上开始）走。

没有练习：问路、记下来这一组（why、askall、memo2、selforder）已从游戏里移除，相关的两条百科（自底向上与自顶向下、记忆化）改在 0-3 之后开放。

原来的前三关「点亮、汇合、接力」（light、merge、relay）也已移除：它们用一套单独的"连箭头"操作，教"格子自动把来路加起来"，和后面在电路板上放汇合器的拼法对不上，本身也几乎没有要想的地方。它们讲的规则由 0-2 直接说出，顺序由 0-3 的结尾点明，「依赖图」百科改挂在 0-2。

| 关 | 名称 | 加回的机制 | 规格要点 | 素材 |

**专题系列：切单词**（一串没有空格的字母，切成词典里的词）

|---|---|---|---|---|

## 10. 对照手册的自检

- **从少量元件起步：** 第 1 代只给汇合器起步，原始元件每关最多新增一个（第 1.1 节）。
- **造出来就能一直用：** 四个封装件都由学习者造出，每个都在后面的关里用到（第 1.3 节）。
- **每层一个新概念：** 每关最多新增一项能力或一个元件。新能力只在地基里出现；新的原始元件在地基里出现，或者作为专题里"加回的那个机制"。练习和挑战不引入任何新东西。
- **专题是同一个问题在长大：** 每个终极谜题的电路板都能解本专题前面的关（各节表下都写了为什么）；E3 用 E2 造的编辑距离计。
- **挑战可跳过：** 每道挑战都挂在某一关之后，不是任何关的先修，都带一个必须失败的 naive 解。
- **机制按需出现：** 5×5 视野、伸缩臂、扫描臂、多层、反复扫，都只在需要它的那一代出现。
