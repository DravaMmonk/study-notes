# 《拆音》（傅里叶变换）：一个切片

工作名《拆音》，专题是傅里叶变换的最上面一层：一段波形是几个纯音按份量叠成的，份量可以从波形里读回来，在份量上动手再叠回去。所有类图灵完备游戏共同遵守的结构、规则和自动检查见 [`games/DESIGN.md`](../DESIGN.md)；本文档只记录这个切片自己的内容。

**它要检验什么**（2026-11-12）：主线只做最抽象一层的概念，关数很少，要用到的复杂元件直接借给玩家；这块元件怎么搭、为什么成立，全部放进支线，愿意的人再下潜。这和手册的自底向上相反，所以先做一个概念看它成不成立，不先改规则。

**现状**：主线四关、一条三关的支线，经操作集写成，`npm run check -- signal --mutants` 清零。没有人试玩过（见第 5 节）。

---

## 1. 机制和值

数据流电路，从 `circuit` 模板生成的 `signal` 领域，元件全在 `parts.json`。线上两种值：

- **数**：一个份量。
- **波形**：24 格，内核的一行网格，用库里的函数图像（`plot`）画。

不用逐拍的原因：一个纯音的份量要看完整段波形才定得下来，逐拍的板只能每拍交出一个还在摆动的中间值，主线上会多出一个和概念无关的障碍。逐拍地累加出份量是《差分机》的事，不放在这里。

三个纯音都是余弦，在整段里来回 1、2、3 次（低、中、高）。只有余弦一种相位，所以这里的波形都左右对称；相位留给以后。

## 2. 地图

| 关 | 做什么 | 带来 | 站在什么上 |
|---|---|---|---|
| 配方 | 任务一：a 份低音。任务二：a、b、c 三个份量叠成波形，收成「合成器」 | 纯音、音量、叠加；波形、纯音、频谱 | |
| 听出配方 | 交出一段波形里三个纯音各自的份量 | 测音（借来的）；傅里叶变换 | |
| 反相 | 任务一：去掉正好 1 份中音。任务二：份量不明，录音里还有三个纯音以外的声音 | 常数；反相 | 测音 |
| 改配方 | 低音和高音的份量对调，中音去掉 | | 测音、合成器、常数 |
| **支线「拆开测音」**，挂在「听出配方」后 | | | |
| 合拍 | 两段波形逐格相乘以后的平均 | 逐格乘、平均；相关、正交 | |
| 自己的测音 | 波形 x 里纯音 t 的份量，收成「自制测音」 | | 逐格乘、平均 |
| 换上自己的 | 用自制测音重做「听出配方」 | | 自制测音 |

主线四关依次是：见到这个概念的一半（合成）、见到另一半（分析）、在波形上用它、把两半接起来在频谱上用它。

## 3. 「借来的」在这一版里是什么

测音是 `parts.json` 里的一个原始元件，运算是领域的引擎资源 `amount`。它明知违反「基础元件最少」：用逐格乘和平均接得出来。支线三关用任务的 `withhold` 把它从托盘收起，让玩家用更小的元件搭出同样的东西。

内核现在分不清「借来的」和「自己搭的」，下面这些这一版都没有，是向内核提的需求：

- 一个元件有内置的和玩家搭的两个来源；搭出来以后，用到它的地方换成玩家自己的板（现在「自制测音」是另一个元件，口也不一样：它把纯音当输入）。
- 地图上「通过」和「点亮」的区别。
- 元件详情里通向搭它的那条支线的入口。
- 按关声明可用的元件集合，和不设锁的大地图。

## 4. 做的过程中定下的

- **收尾关要站在前三关上。** 第一版收尾只是对调两个份量，审计报 `idle-idea`：常数只在「反相」用过一次。改成对调之外再把中音写成 0，常数有了第二处用场，同一件事（去掉中音）在波形上要六块元件、在频谱上只是一个 0，对比也出来了。
- **「反相」挡住了绕路。** 量出三个份量、把中音写成 0、再合成一遍，看上去也能去掉中音。录音里放了三个纯音以外的声音（更高的余弦、正弦、常数偏移），合成器造不出它们，这条路在两个任务上都不过（脚本核对过）。
- **支线里补倍数不用常数。** 支线挂在「听出配方」后，那时还没有常数；相关只有份量的一半，参考解把波形叠上它自己。已经有常数的玩家乘 2 也能过。
- **变异体**：只剩「换上自己的」里三个（自制测音的 x 和 t 对调）。逐格乘不分先后，它们是等价的板。

## 5. 没有验证的

- **核心问题没有答案。** 这一版说明这种编排做得出来、过得了现有的闸门；主线四关能不能不靠讲解让人立住直觉，要真人来玩才知道。
- 「听出配方」的参考解是放三块测音、各接一个输出。它按 `showcase` 过审计，但这正是手册说要警惕的形状；它算不算一道谜题，同样要看人。
- 声音只有图像，没有真的声音。
- 英文只有入门游戏留下的四条。
