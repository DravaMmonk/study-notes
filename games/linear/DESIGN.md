# 《线性之格》设计

从零开始学线性代数：玩家只会把箭头相加、伸缩，一层层搭出矩阵、矩阵乘法、行列式、求解、逆、正交化、特征分解和二次型的元件，最后把这套机器用到多项式这样的抽象空间上。

## 1. 材料与取向

- **主线：3Blue1Brown《线性代数的本质》**（Essence of Linear Algebra，16 集）。它的顺序是"先几何、后计算"：向量 → 线性组合与基 → 线性变换即矩阵 → 矩阵乘法即复合 → 三维 → 行列式即面积倍数 → 逆、列空间、秩、零空间 → 非方阵 → 点积与对偶 → 叉积 → 克拉默法则的几何解释 → 换基 → 特征向量 → 特征值速算 → 抽象向量空间。游戏的每一章跟着这条线走：先让玩家在平面上看见一件事，再让他搭出算它的元件。
- **补充：《理工科大一线性代数读本（精简图解版）》**（同济《线性代数》第五版的路线，六章）。它补主线没有展开的计算和判别：n 阶行列式的排列定义与逆序数、行列式的性质和按行展开、逆矩阵与分块、初等变换与初等矩阵、秩与方程组解的三类、基础解系与通解、施密特正交化、相似与实对称矩阵的对角化、二次型的标准形、配方法与正定判别、线性空间的公理与基变换。读本里"先例子、再定义、再算例"的顺序和关卡的"先遇到、再搭出"一致；它的例题数据直接用作测试（如第 1 章导读的 x + y = 3、x − y = 1，1.1 的 3x₁ − 2x₂ = 12、2x₁ + x₂ = 1）。
- **两者冲突时**，以几何意义先行：读本先讲行列式、后讲矩阵，游戏反过来，先有"矩阵是变换"，行列式作为"面积倍数"出现，读本的展开、排列定义和性质放到需要算三阶、n 阶行列式的地方。

## 2. 机体与机制

- **机制**：数据流电路（`circuit` 模板）。一块板的输入一次流到输出，正适合"给定向量和矩阵，算出一个值"。后面几章还要：消元是同一块小板在每个主元上重复——逐步机器；找特征向量、看二次型的等高线适合参数台（转一个方向看 Av 是否与 v 共线）。这些等到对应章节再加进领域。
- **值**：线上流动三种值——数、向量、矩阵。向量是一列的矩阵（读本的列向量），三者都是 kit 的网格，所以 kit 的显示组件直接能画：数字表（`numbers`）和平面（`plane`）。`plane` 是为这款游戏加进 kit 显示库的：两行的网格每列一支箭头；正好两列时是 2 × 2 矩阵，整张格子跟着 î、ĵ 的落点推过去，单位正方形的像着色，翻面时换一种底色——3B1B 的标志性画面。游戏的默认显示是 `{ "grid": ["plane", "numbers"] }`：二维的值先画成箭头，三维的值画成数字表。
- **领域只有七个引擎资源**（`kit/domains/linear/ops.js`）：`add`、`scale`、`arith`、`entry`、`column`、`vec`、`join`。元件全在 `parts.json`。`vec`、`join` 的后几个口是可选口（kit 的 `optional`），二维、三维共用一块元件。
- **检查不步进**：一块板的结果由输入一次算出，逐个元件步进看不到任何过程，所以关卡界面用 `judged`：按「检查」直接给出每个测试的结果，板上每个元件显示它算出的值。
- **对错**：输出逐个分量比较，差在 1e-9 以内算对，所以 1/3 这样的数和板上的浮点噪声都不会误判；玩家读到的数经 `numberText`，不带噪声。

## 3. 元件依赖

```
原始：相加 add、数乘 scale（带常数 num）、取分量 entry、拼向量 vec、取列 column、并列 join、算数 arith

线性组合 combo  = scale ×2 + add                                    1-4
变换 apply      = column ×2 + entry ×2 + combo                      2-1   Mx：按 x 的分量组合 M 的列
矩阵乘法 compose = column ×2 + apply ×2 + join                       2-4   AB：先 B 后 A
行列式 det      = column/entry + arith（ad − bc）                    3-1
求解 solve      = column ×2 + det ×3 + join ×2 + arith ÷ + vec       3-4   克拉默法则
```

每个搭出的元件都在后面的参考解里用到（`unused`、`bypass` 审计清零）：combo 撑起 1-5 之后的每一关，apply 撑起 compose，compose 撑起 2-5、2-6、3-2，det 撑起 3-2、3-3、solve，solve 撑起 3-5。

## 5. 已做的三章

### 第 1 章 箭头

问题：只会相加和伸缩，能拼出哪些箭头？

| 关 | 名字 | 带来 / 搭出 | 题 | 这一关的新东西 |
|---|---|---|---|---|
| 1-1 | 首尾相接 | 相加 | u + v + w | 向量、和（`showcase`：第一次放元件） |
| 1-2 | 中点 | 数乘、常数 | (p + q) / 2 | 数乘 |
| 1-3 | 从 p 到 q | — | 两个任务：q − p；四分之一处 | 练习：方向（减 = 加掉头的箭头） |
| 1-4 | 线性组合 | 搭出线性组合 | a·v + b·w | 线性组合；点题引出张成 |
| 1-5 | 另一套格子 | 取分量 | 按基 b₁、b₂ 的坐标 c → 那一点 | 基与坐标 |
| 1-6 | 转四分之一圈 | 拼向量 | v 逆时针转 90° | 线性变换：只看 î、ĵ 的落点（naive 解是只交换坐标） |
| 1-7 | 斜推 | — | 剪切，ĵ → (k, 1) | 练习：落点由输入决定 |

1-6 是整章的转折：元件箱里没有"取负"，交换坐标再取负的接法走不通，只能把 v 拆成 x·î + y·ĵ，再按 î、ĵ 的落点重新组合——这正是 3B1B 第 3 集的核心。提示只引导"先看 î、ĵ 去了哪里"。

## 6. 后续章节的要点和对领域的需求

- **第 4 章**：逆矩阵用 solve 搭（逆的第 j 列是 A x = eⱼ 的解），二维够用；三维和一般 n 维要消元。消元是"对每个主元做同一件事"，用逐步机器：机器每一步拿着当前矩阵和主元位置跑一遍玩家的板。需求：领域接 `engine/machine.js`；一块"选取"元件（条件为真取一路，否则取另一路）处理主元为 0 时换行。压扁的变换（det = 0）在平面视图里已经能看见：格子塌成一条线。
- **第 5 章**：apply、compose、det 换代升级到三列（课程的 `replaces`）；三维的值没有平面视图，用数字表；以后可以给 kit 加一个三维的显示方式（斜投影的箭头和格子）。
- **第 6 章**：算数加 √ 选项（选项随章节放出，说明只写已放出的选项）。
- **第 9 章**：特征方向的参数台：转一个方向的旋钮，同时画 v 和 Av；需求：领域的参数台模型项。
- **第 10 章**：二次型的等高线（椭圆、双曲线）需要一种新的显示方式，或参数台的显示项。
