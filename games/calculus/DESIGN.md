# 《差分机》（高等数学）设计框架

工作名《差分机》（The Difference Engine），专题是一元微积分：从一拍算一项的数列机器出发，一章章搭到导数、积分、泰勒级数和微分方程。所有类图灵完备游戏共同遵守的结构、规则和自动检查见 [`games/DESIGN.md`](../DESIGN.md)；本文档只记录这个专题自己的内容，是 agent 流水线（手册第 7.2 节）的课程资料。

**现状**：第 0 章「一拍一项」至第 4 章「面积」已落地；编排在 [`blueprint.json`](blueprint.json)，关卡、文案、百科经操作集写进去。领域在 `kit/domains/calculus`（从脚手架 `tick-bus` 生成）。第 5–7 章仍待设计与实现。

**名字的来历**：巴贝奇的差分机只会做加法，却能一行行印出多项式的函数表，靠的正是第 0 章的那件事：差分一次次做下去，多项式会变成常数；反过来，从常数起一次次累加，就把整张表加回来。微积分是同一件事取极限：导数是差分除以步长，积分是步长乘上的累加。

**学习者：** 会四则运算，不假设学过数列、函数图像以外的任何东西。「极限」「导数」「积分」都在游戏里从头讲起。

**终点：** 学完以后，玩家手上有一台自己搭的机器：给它一个函数，它算出导数、积分、泰勒多项式，解出一个常微分方程，并能说清每一步的误差从哪里来、步长缩小时怎样变小。

## 1. 映射：把《图灵完备》搬到微积分上

| 《图灵完备》 / 已有几款 | 差分机 |
|---|---|
| 原件 NAND | **加、乘、常数、寄存卡**（存一个数到下一拍）。减法、计数、累加、差分都由它们搭出来；后面几章各加一件接不出来的（倒数、比较） |
| 一拍 | **一项**：第 n 拍，板算出数列的第 n 项。时间就是下标 |
| 搭好的电路变成元件 | 下标 n、累加 Σ、差分 Δ，到后面的差商、黎曼和、泰勒展开器、欧拉步进器 |
| 测试 | 给定输入数列，逐拍对照输出的每一项 |
| 失败给出那一组 | 第一处算错的那一项：第几项，应当是多少，算出了多少 |
| 机体 | **数列机**：每拍跑一遍板。第 3 章起数列换成函数在网格上的取样 x_n = a + n·h，同一台机器开始近似连续的东西 |

**要练出的思维：** 一个无穷的对象由「首项 + 怎样从上一项到下一项」完全决定；求和与差分互为逆运算；连续的量是离散的量在步长趋于 0 时的极限；近似一定带误差，误差随步长怎样变小比结果本身更重要。

## 2. 核心机制

### 2.1 一拍一项（逐拍总线的机制，没有共用线）

整个游戏只有一种跑法：第 n 拍，板从头算一遍，算出第 n 项。板每拍什么也不留下，要用上一项，就用寄存卡（存寄存卡、读寄存卡一对）把值留到下一拍。这正是数列的递推：首项是寄存卡的初值，递推式是接到存寄存卡上的那块电路。

用的是逐拍世界（`kit/engine/ticks.js`）：没有线、没有别的节点，世界只按测试把输入数列一拍一项交给板。所以回路必须经过寄存卡，纯组合的回路在编辑器里就被拒绝，和「第 n 项不能取决于它自己」是同一件事。

为什么不是数据流（一根线上整条数列）：那样累加要专门的元件，递推是看不见的；逐拍时累加器就是「寄存卡 + 加」，玩家亲手接出来。

### 2.2 值

- **数**：有理数为主，显示时不带浮点噪声（套件的显示规则）。第 0 章只有整数。
- 「—」：还没有值（寄存卡没设初值时的第一拍）。碰到「—」的元件给出「—」。

### 2.3 下标从 0 起

数列写成 a₀, a₁, a₂, …；差分 Δaₙ = aₙ − aₙ₋₁ 约定 a₋₁ = 0（寄存卡初值 0）。这个约定让「先差分再累加」「先累加再差分」都原样还原数列，第 0 章的核心就落在这里。

### 第 2 章已实现的路线：函数是一张表

| 关 | 动作 | 要辨清的事 | 搭出 |
|---|---|---|---|
| 2-1「铺开网格」 | 用下标算 `xₙ = a + n·h`，换起点、正负步长 | 横轴位置由起点和步长决定，拍数只是取样编号 | 网格 `grid` |
| 2-2「函数值」 | 在网格上逐点算 `f(x) = x²` | 同一个运算规则作用于不同的 `x`，才得到函数的取样表 | — |
| 2-3「从两侧走近」 | 比较 `f(a-h)`、`f(a)`、`f(a+h)`，让 `h` 逐拍缩小 | 从左、右靠近一点是两条不同的取样路线 | — |
| 2-4「台阶函数」 | 搭 `x < 0` 时为 0、否则为 1 的函数 | 一个函数可以在某一点跳变，左右逼近值不同 | 台阶 `jump` |
| 2-5「两侧偏差」 | 用两个距离的较大者量左右样本与中心值的偏差 | 只看一侧可能漏掉跳变 | 偏差 `gap` |
| 2-6「缩小还不够」 | 对平方函数和台阶函数逐拍报告偏差，以及 ε 内最近一段从哪拍开始 | 平方函数在所测两侧越来越贴近中心；台阶在跳变点不会 | — |
| 2-7「直线的应答」 | 给定斜率和 ε，交出一个有效的 δ | ε 决定函数值可以偏离多少；δ 决定输入可以偏离多少 | 直线应答器 `line-delta` |
| 2-8「平方的应答」 | 复用直线应答器，为 `x²` 在不同中心给 δ | 同一个 ε 在不同中心需要不同 δ；用 `2|a|+δ` 控制平方差 | — |
| 2-9「哪里跳」 | 先在台阶函数远离 0 处给 δ，再在 0 处对任意 δ 找反例 | 连续性是逐点判断；在跳点处不存在合格的 δ | — |

这一章仍在同一台逐拍机器上工作。第 2-6 关的 `N` 复用第 1 章的「从此一直」，只报告已测试的拍；`h` 逐拍减半时看到偏差变小，是探索连续性的证据，不是证明。第 2-7 至 2-9 关另有领域判定：它们不规定唯一的输出数列，而按每拍的数学条件检查玩家交出的 `δ` 或反例。对直线，`|m|δ ≤ ε`；对平方函数，`δ(2|a|+δ) ≤ ε`；对台阶函数，离跳点的距离给出安全半径，跳点处则要找 `|x|<δ` 且函数值仍相差至少 `ε` 的点。前两关另要求 δ 不小于指定保守界的四分之一，防止用极小常数绕过 ε 与中心的依赖；这项大小要求是游戏约束，不是连续性的定义。数值条件按机器可表示的数检查，课程只对所给函数族建立结论。

### 第 3 章已实现的路线：斜率

第 2 章能比较邻近函数值，却没有把「变化多少」除以「走了多远」。先搭通用差商 `(f(a+h)−f(a))/h`，再拿平方函数观察它如何随 `h` 改变。平方差分解为 `h(2a+h)`，所以 `h≠0` 时差商恰好是 `2a+h`；`h→0` 给出导数 `2a`。这一步是代数推导，有限测试只检查玩家搭的电路。

| 关 | 动作 | 要辨清的事 | 搭出 |
|---|---|---|---|
| 3-1「两点的斜率」 | 由 `f(a)`、`f(a+h)`、`h` 搭差商 | 函数值差必须除以非零步长 | 差商 `quotient` |
| 3-2「平方的差商」 | 取平方函数在两点的值，复用差商 | 差商为 `2a+h`，依赖中心与步长 | — |
| 3-3「误差还剩多少」 | 逐拍缩小 `h`，同时交出差商及它离 `2a` 的距离 | 差商的误差恰为 `|h|`；趋近不等于已相等 | — |
| 3-4「落在一点的斜率」 | 把代数式里的 `h` 消去，给任意 `a` 交出 `2a` | 导数是差商的极限，不是取 `h=0` 的商 | 平方求导器 `squarePrime` |
| 3-5「和与积」 | 给 `x²`、`3x` 的和与积求导 | 和的导数相加；积的导数有两项 | — |
| 3-6「里面也在动」 | 给 `(x²+1)²` 求导 | 外层变化率乘以内层变化率 | — |
| 3-7「尖点」 | 比较 `|x|` 在 0 左右的差商 | 连续不保证可导；左右极限不一致 | — |

求导法则在本章用明确的多项式与复合函数作代数展开，不宣称有限数值测试证明了任意函数的法则。第 3-7 关把两侧的 `h` 都测出来，避免只从右侧逼近。所有差商测试要求 `h≠0`；在 `h=0` 处直接计算差商没有定义。

### 第 4 章已实现的路线：面积

第 3 章把两个函数值之间的差除以步长；这一章反向操作：每个小格的函数值乘以步长，再把小格累加。先用直线函数看左矩形和的误差如何随步长缩小，再改用梯形与辛普森加权，比较不同近似规则。

| 关 | 动作 | 要辨清的事 | 搭出 |
|---|---|---|---|
| 4-1「一格的面积」 | 高度 `y` 乘有向宽度 `h` | 横轴下方或反向走时面积贡献带符号 | 小格 `cell` |
| 4-2「一格接一格」 | 把每拍的小格累加 | 面积近似是有限分割的和 | 左矩形累加器 `riemann` |
| 4-3「直线下的阶梯」 | 在网格上取 `f(x)=x` 的左端点，逐格累加 | 同一区间切得越细，阶梯越贴近直线 | — |
| 4-4「差半格」 | 给 `h=1/N`，交出 `[0,1]` 下方左矩形和及误差 | 对 `f(x)=x`，左和 `1/2−h/2`，误差为 `h/2` | — |
| 4-5「改成梯形」 | 平均左右端点高度再乘宽度 | 直线在每小格上可由梯形精确覆盖 | 梯形小格 `trap` |
| 4-6「平方的梯形」 | 对 `x²` 逐格积累梯形面积 | 曲线弯曲时梯形仍有误差，缩小步长能减小它 | — |
| 专题「三点加权」 | 用端点和中点的 `1:4:1` 权重算一段 | 辛普森法对三次及以下多项式精确，对更高次仍是近似 | — |

对 `[0,1]` 的 `x²`，复合梯形法在 `h=1/N` 时给出 `1/3+h²/6`，可由有限等差平方和推出；这比左端点矩形的首阶误差下降得快。关卡逐拍显示的是有限分割，不把某一次测试说成积分的定义或误差阶的证明。等式和误差阶在文案中以代数关系说明。

## 4. 第 0 章「一拍一项」

机体：数列机，每拍跑一遍板，读这一拍各输入数列的项，交出这一拍各输出的项。

| 关 | 名字 | 做什么 | 带来 | 搭出 |
|---|---|---|---|---|
| 0-1 | 三列合一 | 三个输入数列逐项相加 | 加；数列与第 n 项 | |
| 0-2 | 上一项 | 每拍交出输入上一拍的项（第一拍 0） | 寄存卡；下标平移 aₙ₋₁ | |
| 0-3 | 等差 | 首项 3、每项加 2 | 常数；递推（首项 + 递推式） | |
| 0-4 | 数数 | 交出 0, 1, 2, … | （练习：下标本身是递推） | 下标 n |
| 0-5 | 平方数 | 交出 n² | 乘；通项公式 | |
| 0-6 | 翻倍 | 首项 3、每项翻倍 | 等比数列（错解：每次加 3） | |
| 0-7 | 累加 | 交出输入的前 n+1 项之和 | 部分和 | 累加 Σ |
| 0-8 | 三角形数 | 0 + 1 + … + n | （练习：对自己算出的数列求和） | |
| 0-9 | 翻倍再求和 | 1 + 2 + 4 + … + 2ⁿ | （练习：等比数列的部分和） | |
| 0-10 | 差分 | 交出 aₙ − aₙ₋₁ | 差分（没有减法：乘 −1 再加） | 差分 Δ |
| 0-11 | 平方的差分 | Δ(n²) | （练习：二次的差分是一次的） | |
| 0-12 | 再差一次 | Δ(Δ(n²)) | （练习：再差一次变成常数：差分机的原理） | |
| 0-13 | 互逆 | 由差分还原数列；由部分和还原各项 | 求和与差分互逆（离散的微积分基本定理） | |

累加和差分两路互不依赖，排成并行组；「互逆」在两路之后汇合，用两件搭出的元件。

## 5. 第 1 章「越来越近」

机体：逼近机，第 0 章的数列机加上倒数和比较；第 0 章搭出的元件全部留着。第 0 章结束时机器算得出任意多项，却说不出 1/2 + 1/4 + … 趋于什么：加到哪一项都不等于 1。这一章把「越来越近」拼成电路：ε-N 定义里的每一个词各是一件元件。

ε-N 用拼电路表达，不做对抗：测试给出 ε（一条常数数列），玩家的板每拍交出「从第几项起一直在 ε 邻域里」，也就是到这一拍为止的 N。N 停住不动，就是这一拍以内找到了 N；N 一直被推后，就是没有。

| 关 | 名字 | 做什么 | 带来 | 搭出 |
|---|---|---|---|---|
| 1-1 | 倒数 | 1/(n+1) | 倒数；无穷小 | |
| 1-2 | 一半再一半 | 1/2 + 1/4 + … 和它与 1 的差距 | （练习：差距是无穷小） | |
| 1-3 | 较大者 | max(a, b) | 比较；把真假当 0/1 乘上去挑选 | 较大者 |
| 1-4 | 距离 | \|a − b\| | 距离 | 距离 |
| 1-5 | 邻域 | \|aₙ − L\| < ε 时为 1 | ε 邻域 | 邻域 |
| 1-6 | 从此一直 | 一串 0/1，交出最近一段连续为 1 从第几项起 | 从某项起 | 从此一直 |
| 1-7 | 极限 | 1/(n+1) → 0，测试给出 ε，交出 N | 极限（ε-N） | |
| 1-8 | 趋于 3 | (3n+1)/(n+2) → 3，数列自己搭 | （练习） | |
| 1-9 | 摆动着靠近 | (−1)ⁿ/(n+1) → 0 | （练习：距离不看方向） | |
| 1-10 | 来回跳 | (−1)ⁿ，L 取几都找不到 N | 发散 | |
| 1-11 | 加得完的无穷 | 1 + 1/2 + 1/4 + … → 2 | 级数收敛：部分和的极限 | |
| 1-12 | 调和级数 | 1 + 1/2 + 1/3 + … 超过任何界 | 项趋于 0，和仍发散 | |

倒数、比较、从此一直三路互不依赖，排成并行组，在「极限」汇合。

**专题 E「算出 e」**（挂在「加得完的无穷」之后）：阶乘倒数 1/n! 由递推 tₙ = tₙ₋₁ · 1/n 算出；累加到 e，用邻域和从此一直看它多快稳定。

**专题 S「巴比伦开方」**（挂在「极限」之后）：xₙ₊₁ = (xₙ + 2/xₙ)/2 从 1 起逼近 √2；看误差每步怎样缩小，比 1/(n+1) 快得多；最后对任意正数 c 开方。

**检查用容差**：数开始带小数，测试的项按相对误差 10⁻⁹ 对照，运算顺序不同造成的末位差别不算错。

**边界**：「从某项起一直在邻域里」说的是无穷多项，板只跑有限拍，N 只在测试的长度内成立；隐藏测试取更长，防住只合前几项的板。文案说「这一拍以内」，不说「证明了收敛」。

## 6. 承认的边界

- 极限在一般情况下不可计算：第 1 章起「趋于」只能判前若干项加容差，或由系统扮演出 ε 的一方。关卡要避开「前 N 项碰巧对、后面不对」能钻的空子，靠隐藏测试取更远的项。
- 浮点：第 3 章起步长取 2 的负幂，网格上的值是二进制精确的；显示一律按有效数字截，不显示噪声。
- 符号的一面（表达式化简、判等）很难做好，只在数值机器能当判定器之后才引入。
