    COMP90086 专题主线、任务与补充关¶

    这是笔记的学习路线及后续关卡设计依据，不是已实现的游戏关卡清单。每项可操作目标见链接词条的“验收（自拟）”；原有游戏和章节 0–1 设计本次未修改。

    主线只使用当前讲义有依据的概念。分类为“应用举例”或“只在 Workshop 出现”的项目全部放在可选专题。每条的直接依赖可点击回读，跨专题依赖在词条中明确列出；不要求把所有专题编号当成唯一线性顺序。

    重要起点必须实际完成：像素坐标 → 局部加权和 → 通道；类别分数 → 损失 → 数据划分；点与线 → 相机 → 极线；概率 → 噪声方差 → 前向扩散；区域 → 邻接图；框 → IoU → 一对一匹配 → P–R → AP。 这些都安排为关卡，不只出现在开场文字中。关卡和任务通过的是明确计算、构造、诊断或追踪行为，不把记术语当验收。

    补充关与支线任务¶

    这些讲义词条不占用上面的主线步位；重要的操作边界安排为补充任务，背景安排为纯文案。它们的前置仍沿用词条声明，不以“补充”删除重要训练。

    词条 形式 为什么保留
    焦距、光圈与景深 补充任务 补足视角、聚焦与景深的取舍。
    阴影、高光与材质 纯文案 解释成像模型的适用边界。
    空间可分离滤波与计算量 补充任务 训练计算拆分与等价性检查。
    硬截断与振铃 补充任务 检查频域截断带来的边缘伪影。
    频域压缩 纯文案 连接频率表示与存储。
    注意力的成本与数据取舍 纯文案 说明全局关系的计算和数据成本。
    纹理偏置与分布变化 纯文案 限制由准确率到泛化的推论。
    可数物体与连续材质 纯文案 说明实例计数的对象范围。
    GrabCut 与框内前景背景 补充任务 补足传统交互前背景分离。
    分割损失与掩码质量预测 补充任务 补足边界加权、掩码学习与质量评分。
    Mask R-CNN 与实例掩码 补充任务 连接目标检测与实例分割。
    视觉词袋与空间信息 补充任务 对照忽略布局与利用空间结构的表示。
    PCA、t-SNE 与表示邻居 补充任务 避免误读表示可视化。
    分类准确率与错误分析 补充任务 补足分类结果的协议与错误分析。
    生成模型的质量与采样成本 纯文案 限制对步数、质量与效率的泛化。
