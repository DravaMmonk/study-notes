    《视觉完备》重制：分章与关卡编排（COMP90086）¶

    状态：2026-11-07。这张图是重制版《视觉完备》的总编排：主线沿用原型《视觉完备》的路线（场景先行、直观理解、用有名字的元件装机器），《视觉实验室》的路线（从原语拆到数学实现）改成挂在主线上的可选原理系列。它取代同名文件此前的三层单线版本和课程大纲第 3、6 节。每关的规格、出处页码、误区和测试还要按流水线逐章写；这里只定到「哪一关回答哪个问题、得到什么、挂在哪里」。章号是游玩顺序，讲次只记出处。

    1. 重制的定位¶

    • 一款游戏。 重制版沿用《视觉完备》的名字，建在 vision 领域上（games/kit/domains/vision/），按章硬切换替掉 games/vision-complete 里 image 领域的原型。《视觉实验室》不再单独成游戏：它已做好的第 0–2 章是主线第 0 章和原理系列 K、F 的素材，内容并入后整个文件夹删除。
    • 原型的关不改，只借想法。 下文每关的「来源」一栏写的是借了哪一关的想法（完 = 原型《视觉完备》，实 = 《视觉实验室》），重写时从规格开始，不搬旧 JSON。
    • 主线讲到理解，原理系列讲到实现。 主线回答「它做了什么、为什么需要、在哪里失效」，并用本章的元件把机器装起来；原理系列回答「它在数组上到底怎么算、约定是什么、代价多大、什么时候不成立」。讲义的每个知识点都在主线上以理解的深度出现一次；原理系列只加深，不承担主线的先修。

    2. 主线和原理系列怎样分工¶

    主线 原理系列
    起点 本章的真实场景，常是上一章机器撞上的墙；章首一关是现象探测 主线上它要拆开的那个机制第一次出现的关（after）
    玩家在做什么 探测黑盒、用有名字的元件组装、在场景里练各个侧面 把主线的预设或搭出的元件拆回原语，推出约定、等价形式和代价，在边界情形上检验
    元件 按手册的最终用途规则定运行方式；主线需要的组装元件都在主线上搭出 拆预设的任务不写 builds，测试对照那块预设；系列内部要复用的仪器在系列里搭出，只给本系列用（optional-built），最后一关可以是只为展示的仪器（showcase）
    不做的事 不把实现细节写进引言和点题 不升级主线的元件（否则主线和支线跑的是两版电路）；不重复主线已经做过的关
    编号 「章-序号」 一条路线一个字母，跨章接续同一个字母

    讲义以外的技术内容（OpenCV 的通道顺序、库函数、实验课步骤）同样只在可选系列里，并进讲同一机制的原理系列或专题，不另开一串。专题（本章的业务场景，以终极谜题收尾）和挑战照手册第 2.4、2.5 节，与原理系列互不依赖。

    依赖是实际用到的元件和知识点。kit 的时代按顺序开放，所以第 3 章、第 7 章虽然只依赖第 0、1 章，也排在第 2 章、第 6 章之后。

    4. 逐章编排¶

    表里「得到」是通过后可用的东西：组装元件（运行玩家电路）标「搭」，代码预设标「预」，显示方式标「显」；运行方式的理由在每章的元件行里。并行组用「｜」隔开各路，最多三路。

    第 0 章 · 质检台（L1–2）¶

    实现入口为开发中的 Vision Lab，与第 1、2 章一同准备切换。

    机器只有逐格的数和算术。墙在后面三章：它不认识邻居（第 1 章）、不认识规则的纹理（第 2 章）、怕换灯（第 3 章）。

    关 名称 问题 玩法 得到 来源
    0-1 一格格数字 机器看到的图是什么：值、坐标、通道 读图填格三任务：照抄、指出坐标、彩色像素的三个数 — 完 0-1、实 0-1
    0-2 底片 每一格各自怎么变 电路 常数、四则运算 完 0-4
    0-3 拉开对比 增益与偏移；超出显示范围的值照样存着 电路 — 完 0-5
    0-4 找不同 两张图哪里不同、差多少：有符号差和它的大小 电路两任务 绝对值 实 0-1
    0-5 未知算子 一块不知道做什么的元件：自己设计输入去探 探测 平移 完 0-2
    0-6 门槛 多大的差才算缺陷 电路 比较 完 0-6
    0-7 挪了一格 零件放偏一格，逐格比对满屏报警 电路 — 实 0-2、完 0-3
    0-8 谁闯进来了 对齐、比较、门槛合起来 电路（组合） — 完 0-7

    排法：0-1 → 0-2 → 并行〔0-3｜0-4、0-6｜0-5〕 → 0-7 → 0-8。挑战「描边」挂在 0-7 之后（平移加比较画出轮廓，限元件数）。

    专题 Q 质检台（挂在 0-8 之后）：Q1 噪声里的划痕（门槛和噪声的取舍）→ Q2 位置不定（几个候选位移里找差最小的）→ Q3 质检台。

    元件：平移、四则运算、常数是原语；绝对值、比较是预设（固定公式，后面的残差和重建误差直接复用）。

    第 1 章 · 扫描仪（L3；L5 的梯度）¶

    质检台一格只看一格：噪声一格一格跳，纸边是一串格子之间的变化。本章给机器装上邻域。

    关 名称 问题 玩法 得到 来源
    1-1 未知模糊器 输出和输入的邻居是什么关系 探测：局部黑盒，单点图、台阶图，提交输入和结论 显 每个邻居的贡献 实 1-1
    1-2 三点平均 怎样把左右邻居拉进同一格 电路 — 完 1-1
    1-3 方块模糊 两个方向一起 电路 — 完 1-2、1-3
    1-4 中间更重 每个邻居一份权重：加权和 电路 搭 滤波器 完 1-4、1-8
    1-5 猜核 只给输入和输出，反推九个权重 电路 — 完 1-9
    1-6 核翻过来 写下来的核与读取方向：卷积和互相关 电路 — 实 1-3
    1-7 图的边上 边外没有观测：补零、复制边缘、循环 电路三任务 滤波器的「边界」设置 完 1-11、实 1-4
    1-8 去噪 平滑压住噪声，也带走细节；高斯比方块好在哪 电路 — 完 1-4、1-13
    1-9 锐化 细节 = 原图 − 模糊，再加回去 电路（组合） — 完 1-5、实 1-6
    1-10 台阶在哪 有符号的差分：变化有方向、有正负 电路 — 完 1-6、实 1-7
    1-11 有噪声的边 垂直方向平滑加差分：Sobel 电路 — 完 1-7、实 1-8
    1-12 梯度 两个方向合成强度和朝向 电路 预 梯度幅值 完 3-7、实 1-8

    排法：1-1 → … → 1-7 → 并行〔1-8、1-9｜1-10、1-11、1-12〕。挑战「5×5 平均」挂在 1-3 之后（计算量上限逼出部分和再挪一挪）。

    专题 S 扫描仪（挂在 1-12 之后，也以 1-8 为先修）：S1 先去噪 → S2 别把图边当纸边 → S3 扫描仪。

    原理系列 K 卷积的实现（挂在 1-7 之后）：

    关 名称 拆开的是什么 来源
    K1 每个邻居一行 窗口表：把邻域展开成行，看每个邻居的贡献 实 1-2
    K2 相乘、求和、还原 一般核的稠密实现；第二个任务先翻核再读，得到卷积 实 1-2、1-3
    K3 反射与有效内区 含边缘样本的反射；有效内区是裁出来的另一种输出，不是补边 实 1-4
    K4 分两次算 可分离：先行后列，和稠密形式在每种边界下等价 实 1-5
    K5 乘法预算 方块、高斯、拉普拉斯在每像素乘法上限下谁能过；拉普拉斯拆不开 实 1-5

    元件：滤波器是组装元件（广：平滑、锐化、梯度、Harris、卷积层、频域对照都用它）；它的最终形态（九个权重、读取方向、边界）在 1-4 到 1-7 一段里搭成，之后不再改结构。可分离形式不进主线：主线没有关需要它的代价。K2 搭出的空间处理器只给 K3–K5 用。

    第 2 章 · 去网纹与缩略图（L4）¶

    印刷网纹规则地铺满整张扫描件，局部平滑要么去不掉，要么连字一起抹掉；缩小图时斑马纹变成粗条。本章给机器装上频率的眼光。

    关 名称 问题 玩法 得到 来源
    2-1 一道波 一道波由哪几个数决定 机关台：频率、相位、振幅互相牵制，对齐目标曲线 余弦 完 2-1、实 2-1
    2-2 叠加 一行复杂的亮度能不能拆成几道波 机关台 — 完 2-2
    2-3 网纹在哪里 一道条纹在频谱上是成对的两个亮点 读图：由条纹的周期和方向指出亮点 显 频谱 实 2 章开章
    2-4 乘了再平均 怎样量出一行里有多少这道波 电路 行平均 完 2-3、实 2-2
    2-5 错开的波 相位一变读数归零；两个正交读数给出幅度和相位 电路 搭 频率探针 完 2-4、2-5、实 2-3
    2-6 对焦了吗 模糊的图高频少 电路 预 频谱 完 2-6
    2-7 两条路 空间里模糊，等于频域里乘一张增益 电路 预 频域滤波 完 2-7、实 2-11
    2-8 低通和高通 留下哪些频率，图就剩什么 电路 — 完 2-8
    2-9 硬切的波纹 一刀切的增益为什么出振铃 电路（辨真伪） — 实 2-10
    2-10 去网纹 只压掉网纹的那几个亮点 电路 — 完 2-9、实 2-9
    2-11 混合图像 低频取一张，高频取另一张 电路（组合） — 完 2-10
    2-12 采样 采样间隔管得住的最高频率；混叠 机关台（提交时判定） 预 隔点取样 完 2-11
    2-13 莫尔纹 直接隔点缩小斑马板；先低通再缩 电路（组合） — 完 2-13

    排法：2-1 → … → 2-7 → 并行〔2-8、2-9、2-10、2-11｜2-12、2-13〕。挑战「一次就够」挂在 2-11 之后（混合图像只准用一块频域滤波）。

    专题 T 缩略图（挂在 2-13 之后）：T1 缩小一半 → T2 缩小四倍 → T3 分两次缩（图像金字塔的计算量）→ T4 缩略图服务。

    原理系列 F 频谱的构造（挂在 2-5 之后）：

    关 名称 拆开的是什么 来源
    F1 扫出整行 探针扫过每个频率：数组顺序、k 与 N−k 成对、零频居中 实 2-4
    F2 装回去 逆合成：系数乘波再求和，正变换除以 N 实 2-5
    F3 幅度换相位 交换两张图的幅度和相位后重建，位置信息在相位里 实 2-6
    F4 复数进来 复数行变换：让变换能接收自己的输出 实 2-7
    F5 两个方向 行变换、转置、再行变换：二维频谱 实 2-8
    F6 二维装回去 二维逆变换，闭合分析和重建 实 2-12
    F7 卷积定理里的 N 循环卷积和频域相乘只差一个由归一化带来的因子 实 2-11
    F8 去条纹仪 只用自己的变换去条纹（showcase） 实 2-13

    元件：频率探针是组装元件（程：两个正交读数怎样合成幅度和相位就是知识点）；频谱、频域滤波、隔点取样是预设。F1、F2、F5 搭出的行频谱、逆合成、二维频谱只在 F 里用。快速傅里叶变换不在讲义的算法范围内，不做。

    第 3 章 · 不怕换灯的质检台（L5）¶
