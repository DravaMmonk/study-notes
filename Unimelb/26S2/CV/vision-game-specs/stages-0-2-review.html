    《视觉实验室》第 0–2 章评审¶

    日期：2026-11-07。范围：第 0–2 章 25 关、44 个任务，内容版本 a502c66（按章节地图和 第 1 章重建规格重建之后）。方法：按手册第 1、4 节和 skill 的 learning-review.md 逐任务读中文的引言、目标、提示、错因和点题，对照参考解；另跑三项只读检查。没有在浏览器里看桌面和手机， 也没有真人试玩：显示是否清楚、新手能否走通，都还未验证。

    结论¶

    处理器的构建阶梯（1-1 到 1-4）和第 2 章由探针到频谱、相位、滤波的主干是好的：每关有撞墙、有不对称或 平移的反例，点题讲原理。问题集中在两处：

    1. 第 1 章后半段变成照方抓药。 1-5 到 1-9 的引言和目标把接法直接说出来（「先平滑再测边缘」「加入 垂直于求导方向的平滑」「选择可分离形态」），提示又给出关键数字；墙没有先出现，玩家只是照做。这正是 重建要补的「先懂在做什么」，现在反而缺得最多。
    2. 第 2 章的「现象」只有两页静态图。 2-1 的频谱是引言里的两张图，结论在玩家看之前就写出来了；2-5、 2-7、2-12 的目标是完整公式，玩家在誊写。

    自动检查¶

    • npm run check -- vision-lab：通过，每个任务的参考解通过、naive 解失败。
    • npm run pipeline -- vision-lab pedagogy：4 处失败，都是重复文字（见 V1、V10）；第 0 章全串行的提示经核对 成立（0-2 用 0-1 的比较，0-3 沿用 0-2 的板）。
    • npm run pipeline -- vision-lab terminology：词条和引用没有错误；6 处「像素」未链接（V15）。

    「阻塞」表示学习上的硬伤，改完才算这几章成立；其余是要改但不阻塞的文案问题。

    第 2 章要补的「现象」¶

    逐个看第 2 章的难点，大多已经由撞墙引出（2-3 的探针在平移下归零、2-6 交换幅度与相位、2-10 的过冲）， 不必加关。缺的只有两处：

    • 频谱表示什么（2-1）：见 V10，从看两张图改成亲手把亮点挪到位。
    • 二维频谱的方向（2-8）：条纹延伸方向和亮点所在方向互相垂直，这一点现在只在点题里说。给 2-8 两个任务 的结果区加上频谱显示（显示库已有，只是内容编排），让玩家在自己的输出上看到它。
