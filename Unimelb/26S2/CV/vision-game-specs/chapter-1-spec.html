    《视觉完备》第 1 章规格：读单据¶

    状态：2026-11-08，按章节地图第 1 章落地的规格。出处：COMP90086 第 2 讲（像素与坐标）、第 3 讲（滤波、卷积、边界、可分离）、第 5 讲（梯度与边缘）。本章不含专题 S 和原理系列 K，它们在主线试玩之后再写。

    机器和元件¶

    机器人要读夜里拍的单据。本章结束时，它有一台自己搭的滤波器，能去噪、找边，最后画出单据边缘的图。

    元件 怎么来 运行 说明
    平移 原语，1-1 预设 把整张图沿横或竖挪一格；图外的值按「图外」设置，第 1–6 关只有「延续边缘」
    四则运算、常数 原语，1-1 预设 常数可以是一个数、三个权重（一行）或 3×3 的核
    拆成三个数 原语，1-4 预设 一行三个权重拆成前、中、后三个数
    拆成三行 原语，1-5 预设 3×3 的核拆成上、中、下三行
    三点平均 → 三点加权 1-1 搭出，1-4 升级 玩家电路 设置：方向（横、竖）、图外。升级后多一个「权重」输入
    滤波器 1-5 搭出 玩家电路 输入：图、核；设置：图外
    向量长度、方向 原语，1-10 预设 一个概念（梯度的大小和方向），同一关带来
    比较 原语，1-11 预设 a < b 为 1，否则为 0

    约定：图外的值默认按「延续边缘」取；坐标 x 向右、y 向下；滤波器按互相关算，核的左上角乘的是左上方的邻居。

    关卡¶

    排法：1-1 → 1-2 → 1-3 → 1-4 → 1-5 → 并行〔1-6、1-7｜1-8、1-9、1-10〕 → 1-11。

    1-1 竖纹¶

    • 动机： 相机传感器每一列的灵敏度略有不同，单据照片上满是一道道竖纹。
    • 玩家做什么： 只有平移、四则运算和常数，压下竖纹。
    • 想到的： 每格和左右邻居平均，各列不同的偏差互相抵消。
    • 测试： 竖纹图（每列一个偏差），期望是左、中、右三格的平均（图外延续边缘）；一组整张同值的图（平均不改变它）。样张：带列条纹的单据。
    • 天真解： 只和一边的邻居平均。为什么错：结果整体往一边偏了半格，左右不对称。
    • 参考解： 往右挪一格、往左挪一格，三者相加，除以 3。
    • 搭出： 三点平均（设置：方向）。

    1-2 夜里的噪点¶

    • 动机： 夜里拍的单据，噪点不只沿横向变，上下也在变。
    • 玩家做什么： 用三点平均压干净。
    • 想到的： 先横着平均，再竖着平均，就是 3×3 的平均。
    • 测试： 噪点图，期望 3×3 平均；只有竖条的图（只横着平均就够、但只竖着平均不够），只有横条的图（反过来）。
    • 天真解： 只横着平均。为什么错：横条纹原样留着。
    • 参考解： 三点平均（横）→ 三点平均（竖）。

    1-3 相机自带的降噪（探）¶

    • 动机： 相机自带的降噪比你的干净，厂家没说它怎么加权。
    • 玩家做什么： 自己画输入喂给它，判断它是哪一种加权：九格一样重、中间重四周轻、只看左右。
    • 想到的： 喂一个亮点，出来的就是它的权重（冲激响应）。
    • 判定： 提交的输入要能把三种解释分开（一整片同样亮的图分不开），选的解释要和输出一致。黑盒的核是 [1 2 1; 2 4 2; 1 2 1] / 16。

    1-4 不一样重（两个任务）¶

    • 动机： 相机的降噪中间重、四周轻，你的三点平均一视同仁。
    • 任务一（接着 1-1 的电路）： 让三点平均能给左、中、右不同的权重。输入：图、权重（一行三个数）。测试：权重 [0.25, 0.5, 0.25]、[0.1, 0.8, 0.1]、[0, 1, 0]。新元件：拆成三个数。
    • 想到的： 平均只是三个权重都是三分之一的加权和。
    • 任务二： 用它复现相机的降噪。
    • 想到的： 中间重的 3×3 权重正好是横向 [1 2 1]/4 和竖向 [1 2 1]/4 先后各做一次。
    • 升级： 三点平均变成三点加权（任务一的电路）。

    1-5 滤波器¶

    • 动机： 相机还自带锐化，它的权重 [0 −1 0; −1 5 −1; 0 −1 0] 拆不成先横后竖。
    • 玩家做什么： 造一台能装任意 3×3 权重的机器。新元件：拆成三行。
    • 想到的： 核的每一行交给一个三点加权（横），各自读上、中、下一行（先把图上下挪一格），三者相加。
    • 测试： 锐化核、相机降噪核、一个不对称的核（左上和右下不同），各一张图。
    • 天真解： 用中间那行的权重先横后竖。为什么错：锐化核拆不开，四角和边上的权重对不上。
    • 搭出： 滤波器（设置：图外，默认延续边缘）。

    1-6 修图滤镜（三个任务）¶

    • 动机： 修图软件的几款滤镜只给了前后照片，要填出它们的权重。板上已经接好：照片 → 滤波器 ← 核（常数，待填）。
    • 任务： 柔化（九格平均）、浮雕（不对称的核）、描边（中间 8、周围 −1）。每个任务的测试里有一张只有一个亮点的图。
    • 想到的： 权重的图案就是效果的样子；但亮点经过滤波器出来的是核转了 180°，要翻回去才是核（卷积和互相关）。
    • 天真解（浮雕）： 照抄亮点的输出。为什么错：互相关的冲激响应是核转 180°，照抄会把效果左右上下都颠倒。

    1-7 黑框（修，两个任务）¶

    • 动机： 一块别人搭的去噪电路，输出四周一圈发黑。板上接好：照片 → 滤波器（图外取 0）← 九格平均的核。
    • 任务一：单据。 纸的四周是同样的纸。改成「延续边缘」。
    • 任务二：花砖。 地砖的花纹是一块块重复的，照片里正好是一整块。改成「循环」。
    • 想到的： 图外没有观测，只能假设；什么假设对，看图外实际是什么。
    • 开放： 这一关起，「图外」可以选取 0、延续边缘、循环、镜像。

    1-8 台阶在哪¶

    • 动机： 纸边是亮度的台阶；去噪会把台阶抹平，得换一种权重找出它。
    • 玩家做什么： 输出两张图：横向的变化、竖向的变化。变亮为正，变暗为负。
    • 想到的： 右边一格减左边一格；权重 [−1, 0, 1]，有正负。
    • 测试： 竖直的台阶（只有横向变化）、水平的台阶、斜的台阶、整片同值（全为 0）。

    1-9 噪声里的边（修）¶

    • 动机： 接着上一关的电路，放到有噪点的照片上，满屏假边。
    • 玩家做什么： 改到只剩真边；期望是 Sobel 的结果。
    • 想到的： 相减把噪声放大；先沿边的方向用 [1, 2, 1] 平滑，再垂直于边相减。
    • 天真解： 不改。为什么错：每个噪点都变成一对正负的假边。

    1-10 边的强弱和朝向¶

    • 动机： 斜的纸边在横、竖两张图里都只出现一半。
    • 玩家做什么： 接着上一关，合成两张图：强度、朝向（以周为单位）。新元件：向量长度、方向。
    • 想到的： 梯度：大小是边有多陡，方向是变亮最快的方向，垂直于边。

    1-11 单据扫描仪¶

    • 动机： 把这一章的零件装起来：夜里拍的单据，画出它的边。
    • 玩家做什么： 先像相机那样降噪，再求梯度强度，强度超过门槛（输入）的格子标 1。新元件：比较。
    • 测试： 带噪点、斜放的单据（小图），门槛 2；一张整片同值的图（全为 0）。样张：大一些的单据照片。

    文案¶

    • 引言每关两三句：上一关到这里卡在哪、这一关补什么。不给公式、不点名用哪个元件。
    • 通关点题一两句：用术语说出刚做成的东西，链接百科。不复述接法。
    • 百科条目：邻域平均、可分离、冲激响应、加权和、滤波器、互相关与卷积、边界假设、图像梯度、Sobel 算子、边缘图。

    验收¶

    • npm run check：每关参考解通过，天真解失败，搭出的元件单独通过搭它的那一关。
    • 浏览器里手机和桌面各走一遍 1-1、1-3、1-5、1-6、1-7、1-11，记下卡住、看不懂、多余的地方。
