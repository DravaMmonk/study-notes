    4 朴素贝叶斯¶

    朴素贝叶斯 (Naive Bayes) 是一种概率分类器 (probabilistic classifier)，它基于：

    • 最大似然估计 (Maximum Likelihood Estimation, MLE)
    • 朴素假设 (naive assumption)

    朴素假设

    • 给定类别时，所有特征条件独立 (conditionally independent)
    • 所有特征对预测的贡献相同

    对于特征向量 \(x = (x_1, x_2, \ldots, x_n)\)，朴素贝叶斯预测：

    \[ \hat{y} = \arg\max_y P(y \mid x) \]

    使用贝叶斯法则：

    \[ P(y \mid x) = \frac{P(y)P(x \mid y)}{P(x)} \]

    由于 \(P(x)\) 对所有类别都是常数：

    \[ \hat{y} = \arg\max_y P(y)\prod_{i=1}^n P(x_i \mid y) \]

    朴素贝叶斯的特点

    优点：

    • 训练简单；计算高效
    • 能很好地扩展到高维数据
    • 可解释的概率模型
    • 天然能处理缺失值
    • 即使独立性假设不成立，效果也常常出奇地好

    缺点：

    • 只要出现一个零，就会让许多其他有意义的观测变得无关紧要
      • 只要任何一项的 \(\text{likelihoods} = 0\)，整个 \(P(y|X) = 0\)
      • 解决办法：平滑 (smoothing)

    平滑方法¶

    Epsilon 平滑¶

    用一个极小的 \(\varepsilon\) 替换零概率：

    \[ P(x_i \mid y) = \varepsilon \]

    拉普拉斯 / 加 \(\alpha\) 平滑¶

    \[ P(x_i \mid y) = \frac{\text{count}(x_i, y) + \alpha} {\sum_j \text{count}(x_j, y) + \alpha K} \]

    其中： - \(K\) = 属性 \(X\) 可能取值的个数
    - \(\alpha = 1\) 时即为加一平滑 (add-one smoothing)

    平滑之后

    • 避免了零概率
    • 降低方差
    • 引入偏差（不再是纯粹的 MLE）
    • 数据集较小时影响很大

    偏差–方差视角¶

    • **方差 (variance)：**训练数据变化时预测会变化多少
    • **偏差 (bias)：**模型期望与真实函数之间的差距

    高方差 → 过拟合
    高偏差 → 欠拟合

    平滑：降低方差，略微提高偏差。

    朴素贝叶斯的变体¶

    高斯朴素贝叶斯¶

    假设：

    \[ P(x_i \mid y) = \frac{1}{\sqrt{2\pi\sigma_y^2}} \exp\left(-\frac{(x_i - \mu_y)^2}{2\sigma_y^2}\right) \]

    MLE 估计：

    \[ \mu_y = \frac{1}{N_y}\sum_{i\in y} x_i \]
    \[ \sigma_y^2 = \frac{1}{N_y}\sum_{i\in y}(x_i - \mu_y)^2 \]

    适用于连续特征。

    伯努利朴素贝叶斯¶

    \[ P(x_i = 1 \mid y) = \theta_{iy} \]
    \[ P(x_i = 0 \mid y) = 1 - \theta_{iy} \]

    适用于二值特征（词袋 (bag-of-words)）。

    类别型朴素贝叶斯¶

    \(K\) 个类别取值 → \(C\) 个类：

    \[ P(X = k \mid y) = \frac{\text{count}(X=k, y) + \alpha} {\sum_{j=1}^K \text{count}(X=j, y) + K\alpha} \]

    带拉普拉斯平滑的标准多项式 MLE。

    对数变换¶

    \[ \log P(y \mid x) = \log P(y) + \sum_i \log P(x_i \mid y) \]
    为什么对数变换有帮助？
    • 防止浮点下溢 (underflow)
    • 把乘积转换为求和
    • 加快计算并提高数值稳定性
