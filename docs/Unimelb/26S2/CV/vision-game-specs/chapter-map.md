# 《视觉实验室》章节地图

状态：2026-11-08。从第一次来玩的人出发设计整门课。主线按课程的概念一个个往上搭；挖技术原理的原理系列、做真实场景的应用关，都是可选支线。本文只定每章做什么、每关让玩家想到什么；每关的测试、文案、出处页码按流水线逐章写（第 1 章见[第 1 章规格](chapter-1-spec.md)）。

## 1. 为谁设计

第一次打开游戏的人，大概是这样：

- 听说过 AI 能认图、能画图、能拼全景、能测距，想知道里面到底怎么回事。
- 会用手机拍照，也许会一点编程；数学停在高中。
- 愿意动脑，但没耐心读长篇说明，更不想背公式。

他想弄懂那些听过名字却说不清的东西：滤波、卷积、CNN、Transformer、扩散模型、目标检测、深度估计，以及它们是怎么一步步长出来的。他要的是概念之间的骨架：每学一个，知道它解决了上一个的什么问题。实现细节和应用场景，是弄懂以后想深挖、想动手时才去的地方。

## 2. 设计原则

1. **主线讲概念。** 主线每关是课程里的一个概念（邻域加权和、冲激响应、梯度、卷积层、注意力……），玩家用和这个概念同一层的元件把它搭出来：讲滤波就给滤波器，讲网络就给卷积层。元件里面怎么算，主线不展开。
2. **原理是支线。** 把主线的预设拆回原语，推出约定（卷积要翻核）、等价形式（可分离）、代价（乘法次数、参数量），放进原理系列（`games/DESIGN.md` 2.4 节）。主线从不依赖它，也不重复它。
3. **应用是支线。** 真实场景（单据、印刷网点、货架、全景照片、零件分拣……）只出现在应用支线：挑战关用已学的概念解一个场景里的「啊哈」，专题把一项完整应用做到底。主线的测试图是中性的：台阶、亮点、条纹、简单图形、合成的带噪照片。整门课不设贯穿的故事。
4. **从小开始。** 第一关一个想法、两三块元件；一关最多带来一块新元件，板子在一章里慢慢变大。小不等于没东西想：每关都要玩家自己搭出结果，只读数、只认识一块元件的不成关。
5. **动机一句话，用上一关的局限说。**「平均把噪点压平了，也把边抹平了」「相减找到了边，也把噪点放大了」。只有新手直觉会给出错误答案的地方，才让他在一关里亲手做错一次（第 3 节）。
6. **抽象一级一级往上搭。** 主线搭出的元件后面真被用到：求梯度 → 边缘检测器 → 角点、直线投票；卷积层 → 残差块 → 编码块（第 7 节逐块核对）。
7. **现代方法从经典方法里长出来。** 机器学出的核就是第 1 章用过的平均核和 Sobel；注意力是不限距离的加权平均；扩散是第 1 章的去噪学出来、做几百遍。
8. **玩法交替。** 搭、探、修、猜、调、训、省（第 4 节），一章里不连着四关同一种。

## 3. 让玩家亲手做错的地方

只有这些地方，新手的直觉会给出错误答案，值得一关让他亲手撞上；其余的动机都只写一句。

| 关 | 新手的直觉 | 实际 |
| --- | --- | --- |
| 1-6 噪声里的边 | 找边就是相减 | 相减把噪声放大成满屏假边 |
| 第 1 章应用·修图滤镜 | 亮点的输出就是核 | 滤波器出来的是核转 180°，照抄效果上下左右颠倒 |
| 2-2 量一道波 | 乘上这道波再平均就量出来了 | 波错开四分之一周期时读数为零 |
| 2-6 一刀切的波纹 | 去掉高频只会更平滑 | 硬切让边旁长出一圈圈波纹 |
| 2-7 隔点取样的陷阱 | 缩小只会损失细节 | 隔点缩小冒出原图没有的粗纹 |
| 3-2 哪个更白 | 亮就是东西白 | 暗东西被强光照，拍出来一样亮 |
| 3-6 不变量的边界 | 色度不随光变就万无一失 | 有色光和阴影下它照样出错 |
| 4-4 分不开 | 叠的层越多越强 | 没有非线性，几层等于一层 |
| 4-8 背答案 | 训练误差低就是学会了 | 验证误差掉头往上 |
| 5-2 训不动 | 越深越好 | 加深一倍，曲线平着不动 |
| 6-4 配对 | 最像的就是对的 | 重复纹理处处配错 |
| 6-6 抽几次才够 | 错配多一倍，多抽一倍就行 | 需要的次数涨得快得多 |
| 7-2 一样大的像 | 大的就是近的 | 远处的大东西和近处的小东西成像一样大 |
| 8-4 打乱了也一样 | 打乱图块，结果会变 | 注意力不认位置，输出不变 |
| 第 8 章应用·数据少的时候 | 新方法总更好 | 数据少时注意力不如卷积 |
| 11-2 中间是空的 | 压缩后的空间处处能用 | 自编码器的潜空间大片画出乱码 |
| 11-5 只会画一种 | 骗过鉴定员就是画好了 | 模式坍塌 |
| 12-2 挡板什么颜色 | 遮住就是去掉信息 | 黑挡板本身被当成了证据 |

## 4. 玩法

| 玩法 | 玩家做什么 | 在引擎里 |
| --- | --- | --- |
| 搭 | 用元件接出一台能通过测试的机器 | 电路任务 |
| 探 | 自己设计输入喂给黑盒，根据输出下结论；只用在探测本身就是方法的地方 | 探测任务（黑盒是本关局部元件） |
| 修 | 一块给定的电路在某些图上出错，找出问题改好 | 电路任务，开局板预置 |
| 猜 | 先写下预测，再运行看对不对 | 选择或读图填格，提交后才显示结果 |
| 调 | 几个旋钮互相牵制，同时满足两个以上的目标 | 参数台，提交时判定 |
| 训 | 搭好带可学习参数的电路，让机器训练，看曲线和学到的参数 | 训练任务 |
| 省 | 同一个目标，限乘法次数或元件数 | 预算挑战 |

## 6. 逐章

每章先写一句学完能做什么，再列主线、原理系列和应用。「想到的」一栏是这一关要玩家自己得出的概念，过关时用术语点名，链接词条。「接着」写这一关从哪块电路开始，空着就是从空板开始。支线写明挂在哪一关之后（`after`）。

### 第 1 章 · 滤波与边缘（L2–3；L5 的梯度）

**学完能做：** 知道一张图上的运算分逐格的和看邻域的，用核描述一台滤波器、用冲激响应认出它，知道边是变化、变化怕噪声；主线最后搭出边缘检测器。

| 关 | 名称 | 玩家做什么 | 想到的 | 玩法 | 接着 |
| --- | --- | --- | --- | --- | --- |
| 1-1 | 反相 | 把一张图变成底片 | 一次运算作用在每一格上（点运算） | 搭 | |
| 1-2 | 模糊 | 用滤波器把噪点压平 | 每格换成周围九格的加权和，权重就是核 | 搭 | |
| 1-3 | 锐化 | 让一张图更清楚，清楚多少由输入定 | 原图减去模糊是细节；把细节加回去就是锐化 | 搭 | |
| 1-4 | 黑盒滤波器 | 自己填输入，判断一台不知道核的滤波器是哪一种 | 喂一个亮点，出来的就是它的核（冲激响应） | 探 | |
| 1-5 | 哪里变了 | 输出横、竖两张变化图，变亮为正 | 边是相邻格的差，差有正负 | 搭 | |
| 1-6 | 噪声里的边 | 上一关的电路放到带噪点的图上满屏假边；改到只剩真边 | 相减放大噪声；先沿边平滑再相减（Sobel） | 修 | 1-5 |
| 1-7 | 边的强弱和朝向 | 由横、竖两张变化图合成强度和朝向 | 梯度：大小是边有多陡，方向是变亮最快的方向 | 搭 | |
| 1-8 | 边缘图 | 强度超过门槛的格子标 1 | 门槛把梯度变成边缘图 | 搭 | |

预设：四则运算、常数（1-1），滤波器和核（1-2；图外默认延续边缘，核按整数写再除以一个数），向量长度、方向（1-7），比较（1-8）。搭出：求梯度（1-6，第 6 章角点用）、边缘检测器（1-8，第 7 章直线投票用）。

原理系列 K 拆开滤波器（挂在 1-2 之后）：K1 三点平均：只有平移和四则运算，邻居就是挪过一格的整张图 → K2 先横后竖：两次三点平均等于九格平均，乘法从 9 次降到 6 次（可分离） → K3 三点加权：平均只是权重相等的加权和 → K4 拆开滤波器：三行加权各上下挪好再相加，和预设的滤波器逐格对上 → K5 卷积：核转 180° 再滤波，就是数学上的卷积。

应用（挑战，挂在各自需要的那一关之后）：
- 竖纹（1-2 之后）：相机传感器三列一组轮流读数，单据照片满是竖纹；只沿横向平均正好一个周期，竖纹消失、字不糊。
- 修图滤镜（1-4 之后）：修图软件的柔化、浮雕、描边只给前后照片，填出核；浮雕不对称，亮点的输出要转 180° 才是核。
- 黑框（1-2 之后）：一块图外取 0 的去噪电路把单据四周压黑；单据要延续边缘，花砖要循环。
- 单据扫描仪（1-8 之后）：带噪点、斜放的单据照片，画出纸边；先降噪再用边缘检测器。

### 第 2 章 · 频率（L4）

**学完能做：** 把图看成一组波，量出某一种波有多少，在频谱上精确地去掉一种纹理，知道缩小前为什么要先模糊；主线最后搭出图像金字塔。

| 关 | 名称 | 玩家做什么 | 想到的 | 玩法 | 接着 |
| --- | --- | --- | --- | --- | --- |
| 2-1 | 拆成波 | 先用「多密、多亮、错开多少」三个旋钮对齐一行条纹；再叠几道波逼近一行明暗台阶 | 一道波由频率、振幅、相位决定；越陡的边要越多高频 | 调 | |
| 2-2 | 量一道波 | 量出一行里某一种波有多少；第二个任务里波错开了一点 | 乘上这道波再平均；错开时要再乘一道错开四分之一周期的波 | 搭 | |
| 2-3 | 频谱 | 先猜几张条纹图的频谱长什么样，再看 | 一组条纹是频谱上的一对亮点：离中心多远是多密，朝哪是条纹的方向 | 猜 | |
| 2-4 | 去掉一种纹理 | 去掉叠在图形上的一组条纹，图形不能糊 | 只压掉频谱上那一对亮点 | 搭 | |
| 2-5 | 模糊在频谱里 | 先预测第 1 章的模糊和锐化把频谱变成什么样，再运行 | 模糊是去掉高频，锐化是抬高高频 | 猜 | |
| 2-6 | 一刀切的波纹 | 一块硬切高频的电路，边旁出了一圈圈波纹；修好它 | 频谱里的断崖在图上变成振铃，过渡要平缓 | 修 | |
| 2-7 | 隔点取样的陷阱 | 隔一格取一格缩小细条纹，冒出了粗纹；改到没有 | 采样太稀时高频冒充成低频（混叠）；缩小前先去掉留不住的高频 | 修 | |
| 2-8 | 采够了吗 | 几组条纹和采样间隔，先判断哪些会出怪纹，再验证 | 每个周期至少采两次 | 猜 | |
| 2-9 | 金字塔 | 缩小八倍不出怪纹，计算量有上限 | 一级一级缩，每级先低通 | 省 | 2-7 |

预设：频谱、频域滤波（2-3），隔点取样（2-7）。搭出：频率测量仪（2-2；原理系列 F 用它）、金字塔（2-9）。

原理系列 F 频谱怎么算出来（挂在 2-3 之后）：F1 让测量仪扫过每个频率，排成一行频谱 → F2 把波按系数加回去，还原原图 → F3 交换两张图的幅度和相位，位置藏在相位里 → F4 先横后竖，二维频谱 → F5 卷积定理：第 1 章的滤波器和频域相乘逐格对上 → F6 只用自己的变换去掉一组条纹。

应用：
- 对焦了吗（挑战，2-2 之后）：同一张单据拍了五张，用测量仪挑出最清楚的。
- 去网点（挑战，2-4 之后）：印刷图的网点去掉，字要清楚。
- 混合图像（挑战，2-5 之后）：做一张近看是扳手、远看是锤子的图，只准用一次频域滤波。
- 专题 T 缩略图回传（挂在 2-9 之后）：T1 条纹包装缩成缩略图 → T2 彩色画面 → T3 带宽更紧。

### 第 3 章 · 光与颜色（L5）

**学完能做：** 知道一个像素的亮度和颜色由光、表面朝向、材质、相机共同决定，知道一张图对应不止一种世界，会造不随光照变化的测量。

| 关 | 名称 | 玩家做什么 | 想到的 | 玩法 | 接着 |
| --- | --- | --- | --- | --- | --- |
| 3-1 | 朝向与明暗 | 给出一个凸起每格的朝向和灯的方向，算出它拍出来的明暗 | 越正对着光越亮，背光为零（朗伯） | 搭 | |
| 3-2 | 哪个更白 | 一张图里左边比右边亮；造出另一个拍出同一张图、右边其实更白的场景 | 一张图对应很多种世界：亮度分不开「东西白」和「光强」 | 猜 | |
| 3-3 | 三个数从哪来 | 由光谱和三条感光曲线算出红绿蓝 | 颜色是对光谱的三个加权和，和滤波器是同一个想法 | 搭 | |
| 3-4 | 光源是什么颜色 | 暖光下的图发黄，校正回来 | 假设整张图平均是灰的，就能估出光源 | 搭 | |
| 3-5 | 只认颜色不认亮暗 | 让测量在光变亮变暗时不变 | 每格除以 R+G+B（色度），消掉光强 | 搭 | |
| 3-6 | 不变量的边界 | 有色光和阴影下，色度测量出错；找出它丢了什么，补上 | 不变量只扛得住它假设的那种变化；梯度朝向不随光强变，可以互补 | 修 | 3-5 |

预设：朗伯着色（3-1 之后）、感光（3-3 之后）。本章只练理解，不造新的组装元件。

应用：
- 专题 P 从明暗看形状（挂在 3-2 之后）：P1 一盏灯不够 → P2 三盏灯解出表面朝向 → P3 找出包装上的凹坑。
- 早晚比对（挑战，3-6 之后）：早晚两张货架照片，光不一样，标出少了的货。

### 第 4 章 · 学习与卷积网络（L6–7）

**学完能做：** 知道「学」就是沿误差下降的方向调参数，看着机器学出第 1 章用过的核，一关关把分类器搭起来；主线最后是一台三类分类器。

| 关 | 名称 | 玩家做什么 | 想到的 | 玩法 | 接着 |
| --- | --- | --- | --- | --- | --- |
| 4-1 | 学出一个核 | 给模糊前后的图，让机器学滤波器的九个权重；再给原图和边缘图 | 学习：往误差下降的方向走一小步，反复走；学出来的就是平均核和 Sobel | 训 | |

**学完能做：** 知道深度为什么让网络看得更远，用残差块训得动深网，用轻量的块省下大半计算，借训好的网络少量样本就学会新类别，会看错例决定下一步。

### 第 10 章 · 检测（L21–22）

**学完能做：** 量出两个框重合多少，去掉重复，给检测器打出公平的分数；再从滑窗一路走到现代检测器。

## 8. 不做成关的东西

- 显示截断和存储的值不同：悬停读数自然说明。
- 视觉任务的几种输出（类别、框、掩码）：各章自然出现。
- 讲义讲到、但这里只进引言和词条的：视觉词袋、GrabCut、实例掩码、分割损失、条件 GAN、潜空间扩散、概率密度。它们要么是已有机器换个用法，要么在浏览器里做不出有意义的实验；以后有合适的玩法再补成关。

## 10. 承认的边界

- 「第一次玩的人想要什么」是推断，没有访谈或试玩数据；每章落地后要找真正的新手试玩，盲玩 agent 本来就懂这些概念，替代不了。
- 每关「想到的」是设计意图，题面和测试能不能真的逼出这一步，写规格时逐关核对：天真解必须是新手真会犯的错，而不是两个输入接反。
- 主线给预设、原理放支线，意味着只走主线的人知道滤波器做什么，却没亲手从平移搭过它；这是有意的取舍，靠原理系列补。
- 训练相关的章能做到多大的模型、多真实的图，取决于浏览器里跑多快，没有测过；做不到的只做成显示和小模型实验，不用滑块凑结论。
- 图的尺寸受浏览器性能限制（现在样例最大 64×64），应用支线里的「单据」「货架」只能是小尺寸的合成图。
- 第 3 章起没有逐页对照原始讲义，写规格时补出处页码。
