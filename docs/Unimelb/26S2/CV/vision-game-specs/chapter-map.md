# 《视觉完备》重新设计

状态：2026-11-08。从第一次来玩的人出发设计整门课，并按《图灵完备》的做法检查过编排和衔接。本文只定每章做什么、每关让玩家想到什么；每关的测试、文案、出处页码按流水线逐章写。

## 1. 为谁设计

第一次打开游戏的人，大概是这样：

- 听说过 AI 能认图、能画图、能拼全景、能测距，想知道里面到底怎么回事。
- 会用手机拍照，也许会一点编程；数学停在高中。
- 愿意动脑，但没耐心读长篇说明，更不想背公式。

他想弄懂那些听过名字却说不清的东西：卷积、CNN、Transformer、扩散模型、目标检测、深度估计、全景拼接，以及它们是怎么一步步长出来的。他想亲手让机器做成看得见的事：给照片去噪、找出单据的边、去掉网纹、拼一张全景、测出前面的东西多远、分拣零件、数清货架、画出没见过的图。他不想抄格子里的数、照一句话接一根线、把滑块拖到变绿。

## 2. 设计原则

1. **一台机器人，一路升级。** 玩家在给一台仓库机器人装眼睛。每章给它装一种本事：读单据、传画面、扛得住换灯、分拣零件、拼出仓库全景、测距避障、以图搜货、抠出零件、盘点货架、给稀有零件补训练图、自查看错了哪里。机器人只是动机的来源，不演剧情。
2. **第一关就做视觉。** 第一块能接线的板，结果就是一张照片变了样。「图是一格格数」靠显示讲：放大看见格子，悬停读出数，不单独成关。
3. **动机一句话。** 为什么需要这一关，在引言里用一句话交代，像《图灵完备》的「想做加法，先得有异或」。只有新手的直觉会给出错误答案的地方，才让他在一关里亲手做错一次（第 3 节）。
4. **每关有一个要玩家自己想到的点。** 题面只说要什么结果，不说怎么算；一句话就能照着接出来的不成关，只是认识一块元件的不成关。天真解是新手真会犯的错，失败时在图上指出错在哪里。
5. **抽象一级一级往上搭。** 先造小零件，下一关用它造大零件：三点平均 → 三点加权 → 滤波器 → 卷积层 → 残差块 → 编码块。每块造出的元件都在后面真被用到（第 6 节逐块核对）。
6. **同一台机器接着改。** 一章里的关尽量接着上一关的电路往下做（`carry`），玩家看着自己的机器一关关变强，而不是每关从空板开始。
7. **现代方法从经典方法里长出来。** 机器学出的核就是玩家第 1 章设计过的；注意力是不限距离的加权平均；扩散是第 1 章的去噪学出来、做几百遍。
8. **作品在主线上。** 每章主线最后一关就是这一章的作品，保证每个玩家都拿到；可选专题是同一件作品的进阶版。
9. **玩法交替。** 搭、探、修、猜、调、训、省（第 4 节），一章里不连着四关同一种。
10. **想深入的可以深入。** 主线讲到能解释、能用；可选的原理系列讲到能推导、能自己从零实现。主线从不依赖原理系列。

## 3. 让玩家亲手做错的地方

只有这些地方，新手的直觉会给出错误答案，值得一关让他亲手撞上；其余的动机都只写一句。

| 关 | 新手的直觉 | 实际 |
| --- | --- | --- |
| 1-6 猜核 | 核写成什么样，效果就朝哪边 | 卷积把核翻过来用，效果左右颠倒 |
| 1-9 噪声里的边 | 找边就是相减 | 相减把噪声放大成满屏假边 |
| 2-3 量一道波 | 乘上这道波再平均就量出来了 | 波错开四分之一周期时读数为零 |
| 2-7 一刀切的波纹 | 去掉高频只会更平滑 | 硬切让边旁长出一圈圈波纹 |
| 2-9 缩小的陷阱 | 缩小只会损失细节 | 隔点缩小冒出原图没有的粗纹 |
| 3-2 换个世界拍同一张图 | 亮就是东西白 | 暗东西被强光照，拍出来一样亮 |
| 3-6 阴影骗了它 | 色度不随光变就万无一失 | 有色光和阴影下它照样出错 |
| 4-5 分不开 | 叠的层越多越强 | 没有非线性，几层等于一层 |
| 4-9 背答案 | 训练误差低就是学会了 | 验证误差掉头往上 |
| 5-2 训不动 | 越深越好 | 加深一倍，曲线平着不动 |
| 6-4 配对 | 最像的就是对的 | 窗格这种重复纹理处处配错 |
| 6-6 抽几次才够 | 错配多一倍，多抽一倍就行 | 需要的次数涨得快得多 |
| 7-2 一样大的像 | 大的就是近的 | 远处的大车和近处的小车成像一样大 |
| 8-4 打乱了也一样 | 打乱图块，结果会变 | 注意力不认位置，输出不变 |
| 8 章挑战 | 新方法总更好 | 数据少时注意力不如卷积 |
| 11-2 中间是空的 | 压缩后的空间处处能用 | 自编码器的潜空间大片画出乱码 |
| 11-5 只会画一种 | 骗过鉴定员就是画好了 | 模式坍塌 |
| 12-2 挡板什么颜色 | 遮住就是去掉信息 | 黑挡板本身被当成了证据 |

## 4. 玩法

| 玩法 | 玩家做什么 | 在引擎里 |
| --- | --- | --- |
| 搭 | 用元件接出一台能通过测试的机器 | 电路任务 |
| 探 | 自己设计输入喂给黑盒，根据输出下结论；只用在探测本身就是方法的地方 | 探测任务（黑盒是本关局部元件） |
| 修 | 一块给定的电路在某些图上出错，找出问题改好 | 电路任务，开局板预置 |
| 猜 | 先写下预测，再运行看对不对 | 选择或读图填格，提交后才显示结果 |
| 调 | 几个旋钮互相牵制，同时满足两个以上的目标 | 参数台，提交时判定 |
| 训 | 搭好带可学习参数的电路，让机器训练，看曲线和学到的参数 | 训练（领域要补，见第 7 节） |
| 省 | 同一个目标，限乘法次数或元件数 | 预算挑战 |

## 6. 逐章

每章先写一句动机和学完能做什么，再列关。「想到的」一栏是这一关要玩家自己得出的东西，过关时用术语点名，链接词条。「接着」写这一关从哪块电路开始，空着就是从空板开始。

### 第 1 章 · 读单据（L2–3；L5 的梯度）

**动机：** 机器人要读夜里拍的单据：照片有噪点，纸放得也不正。

**学完能做：** 自己的滤波器，能去噪、找边，知道它在图边上做了什么假设；作品是从带噪点的照片里找出单据的四条边。

| 关 | 名称 | 玩家做什么 | 想到的 | 玩法 | 接着 |
| --- | --- | --- | --- | --- | --- |
| 1-1 | 去噪点 | 只有平移（整张图挪一格）、四则运算和常数，把噪点压下去 | 每格和左右邻居平均，独立的噪点互相抵消 | 搭 | |
| 1-2 | 两个方向 | 噪点上下也有；用上一关的元件压干净 | 先横着平均，再竖着平均，就是 3×3 平均 | 搭 | |
| 1-3 | 未知滤镜 | 一块黑盒滤镜，自己画输入弄清它对邻居怎么加权 | 喂一个亮点，出来的就是它的权重（冲激响应） | 探 | |
| 1-4 | 不一样重 | 让三点平均能给三个邻居不同的权重，复现黑盒 | 平均只是权重都相等的加权和 | 搭 | 1-1 |
| 1-5 | 滤波器 | 造出能装任意 3×3 权重的机器；浮雕这样的效果拆不成先横后竖 | 三行加权，各上下挪好再相加：一台机器装下所有这类效果 | 搭 | |
| 1-6 | 猜核 | 几轮：照片变成了模糊、锐化、浮雕、右移，填出权重 | 权重的图案就是效果的样子；卷积用核要先翻过来 | 猜 | |
| 1-7 | 黑框 | 一块现成的去噪电路，输出四周一圈发黑；修好它 | 图外没有观测，只能假设：补零、复制边缘、镜像、循环 | 修 | |
| 1-8 | 台阶在哪 | 找出亮度突变处，分出变亮和变暗 | 边缘是相邻格的差，差有正负 | 搭 | |
| 1-9 | 噪声里的边 | 上一关的找边放到噪点照片上，满屏假边；改到只剩真边 | 相减放大噪声；先沿边平滑再相减，两块滤波器串起来就是 Sobel | 修 | 1-8 |
| 1-10 | 边的强弱和朝向 | 横竖两个方向的边合成强度和朝向 | 梯度：大小是边有多陡，方向垂直于边 | 搭 | 1-9 |
| 1-11 | 单据扫描仪 | 从带噪点的单据照片里找出纸的四条边 | 去噪、梯度、每个方向找最强的那一行列 | 搭 | 1-10 |

排法：1-1 → 1-2 → 1-3 → 1-4 → 1-5 → 并行〔1-6、1-7｜1-8、1-9、1-10〕 → 1-11。

搭出：三点平均（1-1），在 1-4 升级成三点加权（三个权重和方向是设置）；滤波器（1-5，由三块三点加权组成）。预设：梯度大小与朝向（1-10 之后）。

挑战：5×5 平均，每格只准乘 10 次（挂在 1-5 之后）。

专题 S 进阶扫描仪（挂在 1-11 之后）：S1 纸是歪的 → S2 纸边贴着图边 → S3 一半在阴影里。

原理系列 K 卷积的实现（挂在 1-7 之后）：K1 把每格的邻居排成一行 → K2 相乘、求和、还原成图，先翻核再读就是卷积 → K3 有效区域：只输出不用假设图外的那部分 → K4 哪些核能拆成先横后竖 → K5 乘法预算：方块、高斯能拆，拉普拉斯拆不开。

### 第 2 章 · 读网点印刷、传回画面（L4）

**动机：** 包装上的印刷图是一片规则的网点，机器人的滤波器要么去不掉网点，要么连字一起抹掉；它还要把画面缩小传回给操作员。

**学完能做：** 把图看成一组波，量出某一种波有多少，在频谱上精确地去掉一种纹理，知道缩小前为什么要先模糊；作品是不出怪纹、又不白算的缩略图回传。

| 关 | 名称 | 玩家做什么 | 想到的 | 玩法 | 接着 |
| --- | --- | --- | --- | --- | --- |
| 2-1 | 一道波 | 用「多密、多亮、错开多少」三个旋钮对齐两张目标条纹图 | 一道波由频率、振幅、相位决定 | 调 | |
| 2-2 | 拼出一个台阶 | 叠加几道波逼近一行明暗台阶 | 什么样的一行都能拆成波；越陡的边需要越多高频 | 调 | |
| 2-3 | 量一道波 | 造一台测量仪：图里有多少某个频率的波；第二个任务里条纹错开了一点 | 乘上这道波再平均；错开时读数会归零，要再乘一道错开四分之一周期的波，两个读数合起来 | 搭 | |
| 2-4 | 对焦了吗 | 同一张单据拍了五张，挑出最清楚的那张 | 用测量仪量高频：越清楚，高频越多 | 搭 | |
| 2-5 | 去网点 | 去掉印刷网点，字要清楚；用测量仪验证网点那个频率没了 | 网点在频谱上是几对亮点（频谱就是对每个频率各量一次）；只压掉那几个点 | 搭 | |
| 2-6 | 模糊在频谱里 | 先预测第 1 章的模糊和锐化把频谱变成什么样，再运行 | 模糊是去掉高频，锐化是抬高高频 | 猜 | |
| 2-7 | 一刀切的波纹 | 一块硬切高频的电路，边旁出了一圈圈波纹；修好它 | 频谱里的断崖在图上变成振铃，过渡要平缓 | 修 | |
| 2-8 | 混合图像 | 做一张近看是扳手、远看是锤子的图 | 远看只剩低频：低频取一张，高频取另一张 | 搭 | |
| 2-9 | 缩小的陷阱 | 隔一格取一格把条纹包装缩小，冒出了怪纹；改到没有 | 采样太稀时高频冒充成低频（混叠）；缩小前先去掉留不住的高频 | 修 | |
| 2-10 | 采够了吗 | 几组条纹和采样间隔，先判断哪些会出怪纹，再在台上验证 | 每个周期至少采两次 | 猜 | |
| 2-11 | 缩略图回传 | 把画面缩小八倍传回，不出怪纹，计算量有上限 | 一级一级缩，每级先低通（图像金字塔） | 省 | 2-9 |

排法：2-1 → 2-2 → 2-3 → 2-4 → 2-5 → 并行〔2-6、2-7、2-8｜2-9、2-10〕 → 2-11。

搭出：频率测量仪（2-3；2-4、2-5 和原理系列 F 用它）。预设：频谱、频域滤波（2-5）、隔点取样（2-9）。

挑战：混合图像只准用一次频域滤波（挂在 2-8 之后）。

专题 T 进阶回传（挂在 2-11 之后）：T1 斜着的条纹 → T2 彩色画面 → T3 带宽更紧。

原理系列 F 频谱怎么算出来（挂在 2-5 之后）：F1 让测量仪扫过每个频率，排成一行频谱 → F2 把波按系数加回去，还原原图 → F3 交换两张图的幅度和相位，位置藏在相位里 → F4 先横后竖，二维频谱 → F5 卷积定理：自己的滤波器和频域相乘逐格对上 → F6 只用自己的变换去网点。

### 第 3 章 · 白天黑夜都看得准（L5）

**动机：** 机器人早晚各拍一次货架，想找出少了什么，可天窗的光和夜里的灯不一样，逐格一减处处不为零。

**学完能做：** 知道一个像素的亮度和颜色由光、表面朝向、材质、相机共同决定，知道一张图对应不止一种世界，会造不随光照变化的测量；作品是早晚两张照片比对出少了哪件货。

| 关 | 名称 | 玩家做什么 | 想到的 | 玩法 | 接着 |
| --- | --- | --- | --- | --- | --- |
| 3-1 | 画一个球 | 给出每格表面朝向和灯的方向，画出球的明暗 | 越正对着光越亮，背光为零（朗伯） | 搭 | |
| 3-2 | 换个世界拍同一张图 | 给一张渲染图，改反射率、朝向、灯强，造出另一个拍出同一张图的场景 | 一张图对应很多种世界：亮度分不开「东西白」和「光强」 | 猜 | |
| 3-3 | 相机的三个数 | 由物体的光谱和三条感光曲线算出像素的红绿蓝 | 颜色是对光谱的三个加权和，和滤波器是同一个想法 | 搭 | |
| 3-4 | 白纸是什么颜色 | 暖光下的照片发黄，校正回来 | 假设整张图平均是灰的，就能估出光源 | 搭 | |
| 3-5 | 只认颜色不认亮暗 | 让测量在灯变亮变暗时不变 | 每格除以 R+G+B（色度），消掉光强 | 搭 | |
| 3-6 | 阴影骗了它 | 有色光和阴影下，色度测量出错；找出它丢了什么，补上 | 不变量只扛得住它假设的那种变化；梯度朝向不随光强变，可以互补 | 修 | 3-5 |
| 3-7 | 早晚比对货架 | 早晚两张照片，标出少了的货 | 用不随光变的测量再比较 | 搭 | 3-6 |

排法：并行〔3-1、3-2｜3-3、3-4、3-5、3-6〕 → 3-7。

预设：朗伯着色（3-1 之后）、感光（3-3 之后）。本章只练理解，不造新的组装元件。

### 第 4 章 · 分拣零件（L6–7）

**动机：** 三类零件，各几百张照片；第 1 章的权重是你一格格设计的，可这回没人说得清该用什么权重。

### 第 7 章 · 测距避障（L2、L12–14）

**动机：** 全景拼接在近处的箱子上出了重影：单应只管得住平面。机器人在货道里走，得知道前面的东西有多远。

**学完能做：** 知道相机怎样把三维压成平面、丢了什么，用两只眼找回深度，知道另一只眼里的对应点只能落在一条线上，认出地上的车道线；作品是避障测距仪。

### 第 10 章 · 盘点货架（L21–22）

**动机：** 盘点要数出每种货有几件；挨着摆的同种货分割成一整片，数不出个数，得每件一个框。

**学完能做：** 量出两个框重合多少，去掉重复，给检测器打出公平的分数；再从滑窗一路走到现代检测器；作品是货架盘点。

| 关 | 名称 | 玩家做什么 | 想到的 | 玩法 | 接着 |
| --- | --- | --- | --- | --- | --- |
| 10-1 | 重合多少 | 判断两个框是不是框的同一件货 | 交集除以并集（IoU），和框的大小无关 | 搭 | |
| 10-2 | 去掉重复 | 一件货三个框，只留一个；两罐挨着的饮料不能被合成一个 | 按分数从高到低，压掉和已留下的框重合太多的（NMS） | 搭 | |
| 10-3 | 公平打分 | 两个检测器，一个框得多、一个框得准，谁更好 | 一对一配上真值，按分数排序算精确率和召回率，取曲线下面积（AP） | 搭 | |
| 10-4 | 每个位置都看 | 用分拣机在每个位置、每种大小上滑一遍 | 滑窗能检测，但算得太多 | 搭 | |
| 10-5 | 框歪了 | 框的大体位置对了，边差一点；让它自己挪准 | 除了分类，再学四个修正量（框回归） | 训 | 10-4 |
| 10-6 | 先猜哪里有东西 | 先在特征图上猜候选框，再细看 | 锚框和候选区域，共享一次特征（RPN） | 搭 | 10-5 |
| 10-7 | 一次看完 | 把图分成格子，每格直接给出框；用轻量块跑得够快 | 一步出框（YOLO），小东西挤在一格会漏 | 搭 | |
| 10-8 | 不要去重 | 让每个查询直接对应一件货 | 对象查询加一对一匹配（DETR），不再需要 NMS | 搭 | |
| 10-9 | 货架盘点 | 数出每种货的件数，用 AP 证明它够准 | 检测器加 NMS，再用自己的 AP 计评测 | 搭 | |

排法：10-1 → 并行〔10-2、10-3｜10-4、10-5〕 → 10-6 → 10-7 → 10-8 → 10-9。

搭出：NMS（10-2）、AP 计（10-3）。预设：IoU（10-1 之后）、一对一匹配（10-8）。

专题 Z 进阶盘点（挂在 10-9 之后）：Z1 大件小件都要 → Z2 货被挡住一半。

### 第 11 章 · 给稀有零件补训练图（L15–17）

**动机：** 有一种零件仓库里只有寥寥几张照片，分拣机总认错；能不能让机器自己画出更多。

**学完能做：** 知道把图压成几个数再还原、怎样让中间的空间连成片好采样、生成器和鉴定员怎样互相逼，以及扩散为什么就是反复去噪；作品是给稀有零件补图，并让第 5 章的分拣机认得更准。

| 关 | 名称 | 玩家做什么 | 想到的 | 玩法 | 接着 |
| --- | --- | --- | --- | --- | --- |
| 11-1 | 两个数记住一张图 | 把零件照片压成两个数再还原 | 瓶颈逼网络只留最重要的东西（自编码器） | 训 | |
| 11-2 | 中间是空的 | 在两个数的平面上走，看还原出来的图 | 自编码器的潜空间有大片空洞，没法随便采样 | 探 | 11-1 |
| 11-3 | 连成一片 | 让潜空间处处能画出像样的零件 | 编码成一团分布，再拉向标准分布（VAE） | 训 | 11-2 |
| 11-4 | 骗过鉴定员 | 生成器和鉴定员轮流训练，让生成的图和真的分不开 | 两个训练互相逼（GAN） | 训 | |
| 11-5 | 只会画一种 | 生成器骗过了鉴定员，却只会画一种零件；改善它 | 模式坍塌：骗过不等于覆盖全部 | 修 | 11-4 |
| 11-6 | 一点点加噪 | 把一张图一步步加噪，直到看不出是什么 | 前向扩散：每步加一点，最后是纯噪声 | 搭 | |
| 11-7 | 猜噪声 | 训练第 9 章的编码解码网络，从加了噪的图里猜出噪声 | 这是第 1 章的去噪，只是学出来的、知道噪声有多大 | 训 | 11-6 |
| 11-8 | 从噪声走回来 | 从纯噪声出发，反复去掉猜出的噪声 | 一步步去噪就能画出新图（反向采样） | 搭 | 11-7 |
| 11-9 | 照着说的画 | 告诉它画哪一类零件 | 把条件喂给去噪网络 | 训 | 11-8 |
| 11-10 | 补训练图 | 给稀有零件画一批图，加进训练，分拣机在真照片上要认得更准 | 生成的图要像、要多样，不能只是记住了那几张 | 训 | 11-9 |

排法：并行〔11-1、11-2、11-3｜11-4、11-5｜11-6、11-7、11-8〕 → 11-9 → 11-10。

搭出：对抗训练（11-4，两个训练控制器交替）、加噪（11-6）、反向采样器（11-8）。预设：重参数化（11-3）。

专题 H 修旧照片（挂在 11-8 之后）：H1 记住了还是画出来的（用第 8 章的近邻查）→ H2 补上划痕 → H3 修一张旧单据照片。

原理系列 D 扩散的数学（挂在 11-6 之后）：D1 两次加噪等于一次加更大的噪声 → D2 一步跳到第 t 步 → D3 猜出噪声就能还原原图 → D4 一千步要算多久（实验）。

### 第 12 章 · 自查看错了哪里（L10、L23）

**动机：** 分拣机在测试集上几乎全对，搬到另一个货架前却一张张认错。

**学完能做：** 给任何一个模型出一张「它在看哪」的热图，知道卷积网络和注意力网络各怎么查；作品是机器人上线前的体检报告。

| 12-2 | 挡板什么颜色 | 黑挡板本身被当成了证据；换一种挡法 | 挡板也是输入，要挡得不带信息 | 修 | 12-1 |

## 8. 不做成关的东西

- 图是一格格数、坐标从左上起、彩色是三个数：第一关的显示（放大、悬停读数、通道切换）。
- 反相、增益与偏移、相减、绝对值、门槛：它们是元件，第一次被需要时直接放进真问题里（扫描仪的判定、早晚比对的阈值），不单独教。
- 显示截断和存储的值不同：悬停读数自然说明。
- 视觉任务的几种输出（类别、框、掩码）：各章的作品自然出现。
- 讲义讲到、但这里只进引言和词条的：视觉词袋、GrabCut、实例掩码、分割损失、条件 GAN、潜空间扩散、概率密度。它们要么是已有机器换个用法，要么在浏览器里做不出有意义的实验；以后有合适的玩法再补成关。

## 9. 做的顺序与引擎前提

- **先做第 1–3 章。** `vision` 领域现有的电路、探测、选择、读图、参数台够用；要补的显示有频谱（能点掉亮点）、梯度朝向箭头、彩色通道切换，以及一章内接着上一关电路开局（`carry`）。
- **第 6、7 章大部分可以接着做**，只有 7-10 要训练。
- **第 4、5、8–12 章先补领域的训练：** 玩家电路要能带参数、求导、被训练控制器迭代，还要训练曲线和学到的核的显示。这一项在 `vision` 领域上还没有。
- **现有内容的去留：** `games/vision-lab` 的第 0 章八关和 Q 专题不再需要；第 1、2 章的任务是 K、F 两条原理系列的素材。第 1 章落地时，`games/vision-complete` 换成新内容，`games/vision-lab` 删除。

## 10. 承认的边界

- 「第一次玩的人想要什么」是推断，没有访谈或试玩数据；每章落地后要找真正的新手试玩，盲玩 agent 本来就懂这些概念，替代不了。
- 每关「想到的」是设计意图，题面和测试能不能真的逼出这一步，写规格时逐关核对：天真解必须是新手真会犯的错，而不是两个输入接反。
- 训练相关的章能做到多大的模型、多真实的图，取决于浏览器里跑多快，没有测过；做不到的只做成显示和小模型实验，不用滑块凑结论。
- 图的尺寸受浏览器性能限制（现在样例最大 64×64），「单据」「货架」只能是小尺寸的合成图。
- 第 3 章起没有逐页对照原始讲义，写规格时补出处页码。
