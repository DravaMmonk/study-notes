# 第 1–12 讲：知识词条、关联与关卡排版（草案）

这一版只覆盖第 1–12 讲，依据仓库里现有的讲义笔记做出。笔记是之前用 AI 整理的，没有对照原始讲义 PDF 和录音转写核对过；抽词条时发现的可疑之处列在「待核」里，接上原始材料后先纠错，再更新受影响的词条和关卡。第 13–22 讲之后按同一方法补做。

关卡不按讲次排，而按**知识线**排：目标是玩家的思维链不中断、吸收的节奏可持续。每关注明出处讲次（L 几）。

## 做法

1. **笔记拆成词条。** 以百科词条为单位：一个概念、模型、关系、方法、限制、Workshop 做法或例子各成一条，覆盖笔记里每个讲了东西的小节。每条有中文正文、笔记原文引用（已逐条核对存在）和出处。
2. **词条分三种性质。** 讲义：课上讲的内容。Workshop：只在 Workshop 或练习里出现，哪怕重要，**一律进可选专题**。应用：例子、历史、笔记说不必背的内容，只写文案。
3. **词条之间建关联。** 每条标出它建立在哪些更浅的词条上（跨讲也标），连成知识图。排版后，相邻两关之间没有直接关联的地方逐对交给审核：后一关是否其实用到了前一关。审核结果：8 对确实用到（原本已间接相连，补成直接依赖），21 对是前一关为后一关铺垫了思路，其余互不相干；另删掉 3 条错标的依赖，并合并 1 对内容重复的词条。
4. **定核心。** 每讲至多两个核心：讲义的难点优先，其次是被点名为重点、或后面依赖多的难点（第 2 讲按笔记的重点、难点手工指定为双线性插值和像素焦距与视野角）。
5. **分层级。** 每个词条落到三层之一：
   - **关卡**：核心；通往核心的阶梯上的台阶和起点（起点即使是直觉点，只要承重就给关卡，承重小的给任务）；讲义点名为重点／难点、或被后面两讲以上用到的词条。
   - **任务**：并进某一关的一个任务。其余有一定重要性的词条、未被点名的难点。
   - **文案**：只在引言、点题或百科词条里出现。例外：视觉任务交出什么形式的答案是一听就懂的事：只写文案（用户裁定）。
6. **按知识线排版。** 硬约束：前置知识一定在用它之前；Workshop 不进主干；每关至多 3 个任务；同一层并行的线至多 3 条。在这之上按代价排：
   - **一条支线一条支线地爬**：每个核心的阶梯沿前置关系往下深挖，较早讲次的材料先爬，最新的支线直接接到核心下面。
   - **先造部件再组装**：阶梯里换支线的地方，两关以上的支线单独成一个**小系列**，爬到它自己的小顶点；核心系列只负责汇合。小系列之间的切换是自然停顿。
   - **台阶按需取用，地基留在本线**：前置词条在第一次被用到的地方出现；但如果好几条线都要用它，或它是在本线核心上的继续（比如 Harris 响应接在角点判别之后），而它所属的线排在前面，就留在本线，作为本线的**延伸**。
   - **防遗忘**：一个前置关卡隔了 8 关以上才再次用到，就在用到它的那一关加一个**回顾任务**，不新增关卡。
   - **长阶梯设小结**：超过 7 关的阶梯在中段设小结点；每关多出来的任务另成紧跟其后的练习关。
   - **补充关卡**（主线没覆盖、但够得上关卡的词条）和**可选专题**（Workshop）挂在相关系列旁边，不堵主干。
