## 1. 单阶段检测：直接预测类别和框

![PDF 13 - YOLO v1](assets/22-object-detection-ii/slide-13.png)

沿网络从左向右看，整图特征最终变成网格上的类别分数和框参数。YOLO v1 不先生成一批候选区域再逐个分类，而是直接预测这些输出。课件右端的“20 类、2 个框”属于所展示的版本与设置，不是所有 YOLO 的固定配置。

SSD 也直接预测类别和框，但在多个分辨率的特征层上放参考框，帮助覆盖不同尺度的物体。单阶段省去显式候选阶段，但仍需要处理类别、位置和重复预测。

## 2. Mask R-CNN：框内哪些像素属于这个物体

![PDF 28 - Mask R-CNN branches](assets/22-object-detection-ii/slide-28.png)

图中 ROI 特征分出类别、框和掩码分支。Mask R-CNN 在 Faster R-CNN 的基础上增加区域内的前景／背景预测，使每个检测实例拥有自己的像素掩码。

语义分割把两头牛都标成“牛”；实例分割还要区分牛 1 与牛 2。两类输出的区别见 [分割第一讲](19-segmentation-i.md#topic-1)，这里关注如何从候选物体区域得到实例掩码。

<a id="topic-3"></a>
## 3. 重点：NMS 去除重复框

![PDF 35 - Duplicate detections](assets/22-object-detection-ii/slide-35.png)

左侧蓝框和橙框主要覆盖同一只狗，IoU 为 0.78；右侧狗的框与蓝框重合很小。若采用课件示例的 0.7 阈值，先保留分数最高的蓝框 0.9，再抑制分数较低、与它高度重叠的橙框 0.8。

重复这个过程，就是非极大值抑制 NMS。通常按类别分别处理。它利用的是预测框之间的重叠，**不需要真实答案框**。拥挤场景中不同物体也可能高度重叠，因此 NMS 可能误删正确检测。

<a id="topic-4"></a>
## 4. 难点：评价要同时检查排序、类别和位置

对一个类别，把所有检测按分数从高到低排列，再用给定 IoU 阈值与真实框匹配。一个真实物体不能反复为重复检测加分。随着纳入更多低分检测，计算：

$$
\mathrm{Precision}=\frac{TP}{TP+FP},\qquad
\mathrm{Recall}=\frac{TP}{N_{\mathrm{GT}}}.
$$

 $TP$ 是正确匹配的检测数， $FP$ 是错误检测数， $N_{\mathrm{GT}}$ 是真实物体数。Precision 问“报出的有多少是对的”，Recall 问“实际存在的找到了多少”。沿分数顺序累积，可得到 P–R 曲线。

![PDF 50 - Class and IoU averaging](assets/22-object-detection-ii/slide-50.png)

课件把单类 AP 解释为 P–R 曲线下面积；mAP 再对类别取平均。图中鸟、猫、狗的 AP 分别为 0.65、0.80、0.86，平均为 0.77。COCO mAP 还对多个 IoU 阈值的结果取平均，因此通常比只用 0.5 阈值的成绩更严格；具体计算细节应保持同一评价协议。

**易错**：NMS 的 IoU 阈值决定哪些预测框被删；评价的 IoU 阈值决定预测与真实框是否足够接近。两者都用 IoU，却不承担同一任务，也不必取同一个数值。高 mAP 仍不能代替对漏检、误检和定位偏差的具体分析。
