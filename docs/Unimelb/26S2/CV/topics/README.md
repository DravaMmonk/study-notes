# COMP90086 装置图鉴

这里把整门课的核心概念做成了 16 台可以动手操作的"机器"。每台机器的运动就是概念本身：针的高度是像素值，垫圈数是权重，弹簧把相似的表示拉到一起。机器上不写字，读数在卡片右下角，计算过程在卡片下方。

**怎么用**：先读讲义里的那一小节，再来玩对应的装置；或者复习时按专题从头玩一遍，每篇末尾的"动手自测"都能靠操作装置回答。每台装置不操作时会自动演示；鼠标悬停、方向键和卡片下方的按钮可以接管。在 Fieldnotes 里阅读时才能看到装置，Obsidian 和 MkDocs 中只显示文字。
