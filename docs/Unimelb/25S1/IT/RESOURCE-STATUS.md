## 尚未完整或需要区分的项目

- **Transport Layer (1)、(2) 讲义没有恢复。** Week 8 模块列表中没有讲义条目，Week 9 页面只有 Transport Layer (3)。Transport Layer (3) 的页脚从 57 开始，说明前两份讲义合计约 55 页。[09](09-transport-layer-udp-tcp.md) 因此以 `Week12-Review-Lecture3.pdf` 的传输层页为讲义来源，并用学生笔记中的 16 张截图（`note-01`–`note-16`，取自周笔记 "WEEK 8 - Transport Layer"、"WEEK 8-9 - Transport2 - UDP & TCP"、"WEEK 9 - Transport3 - TCP Management"）补足。这些截图来自未恢复的讲义或课堂板书照片，不能标注 PDF 页码，分辨率以学生原图为准；其中一张有学生手写的笔误，已在笔记中标出。
- **Tutorial 资料不在本地。** 这次恢复只取讲义页面上的文件，Canvas 的 Tutorial 页面、题目与答案都没有下载；本地也没有作业或考试文件。
- **文件名与内容不一致。** `Week9-Transport Layer-Lectures2and3.pdf` 首页是 Transport Layer (3)；`Week4-Lectures23-*.pdf` 两个文件分别是 Data Link Layer (3) 与 MAC Sub-Layer (1)；`W3-L2-example_solutions.pdf` 属于 Physical Layer (2)（页脚 45–47）；`example_solutions.pdf` 文件名不含周次，内容是 Physical Layer (1) 的例题（页脚 8–9）。归档以首页标题与内容为准。
- **Week 6 讲义的讲次是推断的。** 三份文件依次为 Network Layer (2)、(3)、(4)，据此把 `Week6-routing.pdf` 认作 W6-L3；Week 7 页面写明沿用 W6-L3。
- **学生笔记的周次与分讲编号。** 学生的 "Network2"、"Network3"、"Transport4" 分别对应讲义 Network Layer (3)、(4) 与 Transport Layer (3)；"WEEK12 - Internet Security" 同时覆盖 Network Security (1)（Week 11 文件）与 (2)。Week 11 的流媒体与电子邮件没有单独的周笔记，只有复习笔记 "Application Layer" 涉及。

- **讲义中的笔误** 在相应笔记中以 **易错** 或 `延伸内容` 标出，不改动原文件：`Week6-IP.pdf` p.13 图中把 `192.24.12.0/22` 印成 `192.2412.0/22`（[07](07-ip-addressing.md)）；`Week10-Application Layer-Lecture1.pdf` p.19 把 washington 拼成 "aashington"（[11](11-dns-and-www.md)）；`Week11-Lectures2&3.pdf` p.20 把 3DES 的密钥空间写成 $3\times2^{56}$ 、把 AES 写成"128–256 位分组"（[13](13-cryptography.md)）；`Week9-Transport Layer-Lectures2and3.pdf` p.15 标题 "half of previous" 指丢包时的拥塞窗口，容易误读为旧阈值（[10](10-congestion-control.md)）。复习答案中 CFB 的"前 8 个密文块"应为前 8 个密文字节。学生笔记的笔误（以太网最小帧长、DNS 端口、校验和回卷、Go-Back-N 的 NAK 等）同样在相应位置标出。
